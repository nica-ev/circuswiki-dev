# Ballonnen Balanceren

Een spel voor kleine tot grote groepen.

Benodigdheden: Ballonnen

Een eenvoudig spel om de basis van balans te oefenen.

Iedereen neemt een ballon en probeert deze zo lang mogelijk op verschillende lichaamsdelen te balanceren.
Bijvoorbeeld op de neus, op het hoofd, op de uitgestrekte vingers, de vuist, enzovoort.
