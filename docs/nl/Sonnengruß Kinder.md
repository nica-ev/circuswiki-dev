# Zonnegroet voor Kinderen

De zon komt op (strekken)
De zon gaat onder (buigen)
Ze wekt het ene been op (Krijgerhouding)
het andere wordt wakker (opdrukken)

Ze wekt de rups (op de grond liggen)
Ze wekt de slang (steunen op de armen, achteroverbuiging)
Ze wekt de hond (hondenhouding)
Dat duurt niet lang

Het andere been weer terug (Krijgerhouding andersom)
De zon komt op (strekken)
Wat een geluk ([[Namaste]])
