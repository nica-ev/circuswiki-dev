# Aplikacja do cyrku

Gra dla średnich i dużych grup:

Wszyscy uczestnicy siedzą w kręgu. Wyznaczana jest jedna osoba (kandydat), która musi opuścić pomieszczenie.

Następnie wybierany jest dyrektor cyrku.

Kandydat wraca do pomieszczenia i ma trzy próby, aby zidentyfikować dyrektora cyrku.

Dyrektor cyrku w tym czasie stale wykonuje ruchy, które wszyscy pozostali muszą naśladować. Musi starać się wykonywać je jak najmniej rzucając się w oczy, tak aby kandydat widział od wszystkich osób jednocześnie ten sam ruch.

Jeśli kandydat odgadnie, kto jest dyrektorem, wygrywa grę.
Jeśli mu się nie uda, wygrywa grupa.
