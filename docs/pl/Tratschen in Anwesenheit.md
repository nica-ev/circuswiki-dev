# Plotkowanie na obecność

Gra poznawcza dla małych grup (idealnie 3-6 osób)

Wybierana jest jedna osoba, o której głośno się plotkuje lub snuje domysły. Osoba ta przez cały czas siedzi po cichu, słucha wszystkiego, ale niczego nie komentuje ani nie poprawia.

Tematy takie jak stan cywilny, pochodzenie, zainteresowania, gust muzyczny itp.

Po pewnym czasie osoba ta wyjaśnia wszystko lub prostuje błędne domysły.

Następnie przychodzi kolej na następną osobę, aż wszyscy z grupy będą mieli swoją kolej.
