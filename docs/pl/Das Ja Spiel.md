# Gra "Tak"

Gra aktorska

Jedna osoba coś proponuje, np. „Wszyscy czytamy gazetę”, „Wszyscy tańczymy w kółku”, „Wszyscy skaczemy jak żaba”.

Grupa wspólnie odpowiada „TAK!!!!” i zaczyna wykonywać proponowaną czynność. Dzieje się tak do momentu, aż ktoś inny zaproponuje nową czynność.
