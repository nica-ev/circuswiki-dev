# 1, 2, 3

Gra dla każdej wielkości grupy:

Tworzone są pary.

**1. Runda:** Partnerzy stają naprzeciwko siebie i na zmianę liczą 1, 2, 3 (Max: 1, Linda: 2, Max: 3, Linda: 1, Max: 2...).
**2. Runda:** Zamiast mówić „1”, teraz klaszczemy (Max: klaszcze, Linda: 2, Max: 3, Linda: klaszcze, Max: 2...).
**3. Runda:** Zamiast „2” teraz podskakujemy w miejscu (Max: klaszcze, Linda: podskakuje, Max: 3, Linda: klaszcze, Max: podskakuje, Linda: 3...).
**4. Runda:** Zamiast „3” obracamy się raz wokół własnej osi (Max: klaszcze, Linda: podskakuje, Max: obraca się, Linda: klaszcze...).

Rundy można następnie "rozbierać" od tyłu do przodu, aż dojdzie się z powrotem do początkowego liczenia.
