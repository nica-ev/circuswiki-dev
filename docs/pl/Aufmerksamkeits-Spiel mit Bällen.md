# Gra na koncentrację z piłkami

Gra dla małych i średnich grup.
Wszyscy swobodnie biegają po wyznaczonym obszarze gry.
(zobacz też: swobodne bieganie / ćwiczenia teatralne / wypełnianie przestrzeni)
Jedna osoba ma piłkę. Ta osoba nawiązuje teraz kontakt wzrokowy z inną osobą podczas biegu i rzuca jej piłkę.

Ważne: osoba docelowa powinna być stosunkowo blisko; rzucaj dopiero po nawiązaniu kontaktu wzrokowego.

Poziom trudności można dowolnie zwiększać, zwiększając liczbę piłek.
