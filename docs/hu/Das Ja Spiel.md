# Az Igen Játék

Színjáték

Egy személy felkiált valamit, pl. „mindannyian újságot olvasunk”, „mindannyian körbe táncolunk”, „mindannyian úgy ugrálunk, mint egy béka”.

A csoport közösen felkiált: „IGEN!!!!”, és elkezdi végezni a tevékenységet. Ez addig tart, amíg valaki más nem kiált fel egy új tevékenységet.
