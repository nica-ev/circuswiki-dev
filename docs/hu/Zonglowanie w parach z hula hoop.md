# Páros hula hoop-ozás

Párban végzett gyakorlat, amely fejleszti az együttműködést, a ritmust, az időzítést és a karikával való munkát.

## I. szakasz

Két hula hoop párként.

Szinkronban gyakorlunk:

1. Gurítás.
2. Dobás.

## II. szakasz

Négy hula hoop párként.

Szinkronban gyakorlunk:

1. Gurítás.
2. Dobás.
3. Gurítás és dobás.
4. Az összes szakaszt ismételjük aszinkron módon.
