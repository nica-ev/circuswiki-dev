# Lufballon egyensúlyozás

Játék kisebb és nagyobb csoportoknak.

Kellékek: Lufik

Egyszerű játék az egyensúlyozás alapjainak gyakorlására.

Mindenki fog egy lufit, és megpróbálja minél tovább egyensúlyozni különféle testrészein.
Például: az orrán, a fején, kinyújtott ujjakon, öklön stb.
