# Bomba Játék

> [!info] Rövid leírás
> A "Bomba Játék" egy dinamikus fogójáték közepes csoportok számára, ahol az elkapott játékosok "ticking bombákká" válnak, és csapatmunkával kell megmenteni őket, mielőtt "felrobbannak".

**Csoportméret**: Közepes
**Nehézség**: Egyszerű
**Anyag**: Nincs
**Játékidő**: Kb. 15-20 perc

## **Játék leírása**:

Egyszerű fogócska. A csoport méretétől függően egy vagy több fogót jelölünk ki. Ha valakit elkapnak/megérintenek, az "bombává" válik.

Terpeszben áll, karjait lefelé kinyújtva. Hangosan számol: "1, 2, 3, 4, 5".
Minden számra egy kicsit felemeli a karjait, míg 5-nél a feje fölött összeérnek.

Ekkor a "bomba felrobban": a személy teljesen kiesik a játékból, és leguggol (vagy elhagyja a játékteret).

Egy "ticking bombát" úgy lehet megmenteni, hogy egy másik személy odamegy, és mindkét kezével a vállára koppint.
