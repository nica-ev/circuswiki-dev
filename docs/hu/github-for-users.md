# Közreműködés a dokumentációban – Így csináld könnyedén!

Sziasztok! Örülünk, hogy segíteni szeretnétek a dokumentációnkban. 😊 Íme egy egyszerű útmutató, hogyan tehetitek meg:

## Amire szükséged lesz

1.  **GitHub-fiók:**
    *   Hozd létre az ingyenes GitHub-fiókodat, ha még nincs: [https://github.com/join](https://github.com/join)
    *   Erre azért van szükségünk, hogy minden rendben működjön.

2.  **GitHub Desktop:**
    *   Töltsd le és telepítsd a GitHub Desktopot: [https://desktop.github.com/](https://desktop.github.com/)
    *   Ez a program megkönnyíti a Git használatát, még akkor is, ha nem vagy vele teljesen tisztában.

## Kezdjük!

1.  **A repository (tár) másolása:**
    *   Menj a dokumentációs részlegünkhöz a GitHubon (pl. `nica-ev/docs`), és kattints a "Fork" gombra.
    *   Ezzel létrehozol egy saját másolatot a területről, ahol dolgozhatsz anélkül, hogy bármit elrontanál. 😉

2.  **A repository letöltése a számítógépedre:**
    *   Nyisd meg a GitHub Desktopot.
    *   Kattints a "File" -> "Clone repository..." lehetőségre.
    *   Válaszd ki a GitHubon lévő másolatodat a listából.
    *   Tallózz be egy mappát a számítógépeden, ahová menteni szeretnéd a területet.
    *   Kattints a "Clone" gombra.
    *   Most már a repository másolata ott van a számítógépeden.

3.  **(Opcionális) Új munkaág (branch) létrehozása:**
    *   Kattints a GitHub Desktopon az "Current Branch" gombra (általában bal fent).
    *   Adj meg egy új nevet a munkaágadnak (pl. `uj-lap`, `hiba-javitas`).
    *   Kattints a "Create branch" gombra.
    *   A munkaágak segítenek elkülöníteni a módosításaidat. Ha valami balul sül el, a munkaágat egyszerűen törölheted.
    *   **Megjegyzés:** Az új munkaág létrehozása opcionális, de jó ötlet a módosításaid rendszerezéséhez.

4.  **Módosítások végrehajtása:**
    *   Használd a szövegszerkesztődet (pl. Jegyzettömb, VS Code) a számítógépeden lévő fájlok szerkesztéséhez.
    *   Itt adhatsz hozzá szöveget, javíthatsz hibákat és így tovább.
    *   **Fontos:** Használd a Markdown formázást (lásd alább).

5.  **Módosítások mentése:**
    *   A GitHub Desktop "Changes" (Változások) fülén látod a módosított fájljaidat.
    *   Írj egy rövid összefoglalót az "Summary" (Összefoglalás) mezőbe.
    *   Kattints a "Commit to `<branch-name>`" gombra (vagy "Commit to main", ha nem használtál munkaágat).
    *   A mentés olyan, mint egy pillanatkép a munkádról.

6.  **Módosítások feltöltése:**
    *   Kattints a GitHub Desktopon a "Push origin" gombra.
    *   Ezzel feltöltöd a módosításaidat a GitHubon lévő másolatodba.

7.  **Módosítások beküldése ellenőrzésre:**
    *   Kattints a GitHub Desktopon a "Create Pull Request" gombra. Ezután megnyílik egy oldal a GitHubon.
    *   Ott ellenőrizd a módosításaidat, majd kattints a "Create Pull Request" gombra.
    *   A Pull Request (vagyis húzási kérelem) olyan, mint egy kérés a módosításaidnak a fő repositoryba való beépítésére.

## Fontos tudnivalók

*   **Markdown:** Ez egy egyszerű szövegformázási nyelv. Íme egy rövid áttekintés:
    *   `# 1. szintű címsor`
    *   `## 2. szintű címsor`
    *   `**Félkövér**`
    *   `*Dőlt*`
    *   `- Listaelem`
    *   `[Link](https://www.example.com)`
*   **Mentési üzenetek:** Írj rövid üzeneteket a mentési műveletekhez, hogy mindenki tudja, mit csináltál.
*   **Türelem:** Az elején lehet, hogy egy kis gyakorlatot igényel. Csak kérdezz, ha valami nem világos!

Köszönjük a segítséged! 🙌
