# Workshop Theme: Pirates

It's particularly effective to integrate circus disciplines thematically, especially for kindergarten-aged children. A popular theme is certainly "Pirates."

Simple ways to incorporate rope balancing include:

- crossing a deep chasm in search of pirate treasure

Thematic applications can be found for (almost) all disciplines in a similar way.

- Aerial arts: climbing the ship's rigging
- Scarf juggling: red scarves are used as a fire where marshmallows/apples are roasted; these get hot and must be thrown from hand to hand
