# Sorting in the Group

A cooperative game for small to medium-sized groups.

Props: Chairs or stools, etc., one for each person.

The chairs are arranged in a circle with a small gap between them, so that one can comfortably move from one chair to the next.

Each person now steps onto a chair. The task is for the group to sort themselves without anyone touching the floor.

Sorting can be done, for example, by name, height, age, etc.

As an added challenge, verbal communication can be forbidden.
Arranging the chairs in a line instead of a circle also makes the task more difficult.
