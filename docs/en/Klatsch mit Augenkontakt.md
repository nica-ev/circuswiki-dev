# Clap with Eye Contact

A clapping game for any group size:

Everyone stands in a circle.
The group leader starts by making eye contact with any person in the circle and giving them a clap. That person then makes eye contact with someone else and passes the clap to them...
The game leader can introduce any number of additional claps into the circle. When a clap returns to the leader, it is no longer passed on.
The game ends when all the claps have returned to the game leader.
