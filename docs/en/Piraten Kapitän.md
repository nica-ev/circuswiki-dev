> [!info] Short Description
> A themed command game on a pirate ship where pirates react and flee from sharks.

**Group Size**: 5-25 people
**Difficulty**: Easy
**Materials**: Mat
**Duration**: 5-15 minutes

## **Game Description**:

A themed game for small to medium-sized groups.
The game leader is the pirate captain.
A large mat (e.g., a soft mat) represents the pirate ship where all the pirates are located.

The captain can then issue various commands. For example:
"All to port!"
"All to starboard!"
"Scrub the decks!"
"All hands row!"

"All hands overboard!" - Upon this command, all pirates jump off the ship and swim around.
Before the game begins, 2-3 sharks are designated. At the command "The sharks are coming," these sharks swim in and try to "eat" pirates (who then become sharks themselves).
The pirates try to get back onto the ship as quickly as possible.
