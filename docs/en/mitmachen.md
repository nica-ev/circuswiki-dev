You are cordially invited to contribute to the documentation.
Possible topics include:
- Tutorials
- Game descriptions
- Changes / additions to existing pages
- or anything else =)

## Text Documents
The easiest way to contribute is to send us your content as a text document (Word, Markdown, TXT, etc.) via email (mailto:info@nica.network).

# Wordpress Pages / Blog
If you prefer to create your content in WordPress, simply send us the link to the page. In most cases, the content can be transferred relatively easily.

# Editing / Adding to Our Documents
This is a bit more technically involved, but it offers the ability to edit the entire documentation in Markdown format (e.g., with Obsidian).
