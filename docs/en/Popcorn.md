> [!info] Short Description
> A dynamic tag game for any group size, ideal as a warm-up activity, where participants transform from "corn kernels" into bouncing "popcorn."

**Group Size**: Any
**Difficulty**: Easy
**Materials**: None
**Duration**: Approx. 10-15 minutes

## **Game Description**

A tag game suitable for any group size, great for children and as a warm-up activity.

At the start of the game, all participants are "corn kernels." The floor represents a hot stovetop.
Everyone moves around as if the floor is extremely hot (feet are placed down and lifted very quickly). No running is allowed.

Throughout this, everyone continuously shouts "hot, hot, hot, hot."

Initially, one or more people (depending on group size) are chosen to be the first "popcorn." These individuals bounce around with large leaps, constantly shouting "Pop, pop, pop, pop."

If this "popcorn" bumps into a "corn kernel," the "corn kernel" also transforms into "popcorn" and begins bouncing around.

The game ends when all "corn kernels" have become "popcorn."
