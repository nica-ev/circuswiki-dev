# 1,2,3

Game for any group size:

Pairs are formed.

**1. Round:** The partners stand facing each other and alternately count 1, 2, 3 (Max: 1, Linda: 2, Max: 3, Linda: 1, Max: 2...).
**2. Round:** Instead of saying 1, a clap is now made (Max: claps, Linda: 2, Max: 3, Linda: claps, Max: 2...).
**3. Round:** Instead of 2, a jump on the spot is now made (Max: claps, Linda: jumps, Max: 3, Linda: claps, Max: jumps, Linda: 3...).
**4. Round:** Instead of 3, a turn on the spot is now made (Max: claps, Linda: jumps, Max: turns, Linda: claps...).

The rounds can then be dismantled again from back to front until the initial counting is reached again.
