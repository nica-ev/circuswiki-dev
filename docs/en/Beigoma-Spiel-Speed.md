Introduction to the Game "Speed"
Game Description

This game can be played with many people. (It's also possible with a small number of players.)

You can adjust the number of rounds based on the number of participants and the playtime.

The number of rounds can be adjusted depending on the number of participants and the playtime. 10 rounds for a short game, 30 rounds for a long game.

Since the game is played with four players simultaneously, it's a game with a high element of luck.

Therefore, it can be played by beginners and advanced players alike.

The game is called "Speed" because many rounds are played in quick succession. In some regions, the game is named after the number of rounds, "00 times."

Rules

4 players enter at the same time.

There is a game of chance.

Use a normal dice.

Game Scoring

Win: 3 points
Draw: 1 point
Loss: 0 points

The point distribution varies by region.

Game Flow

Each player receives a card and writes their name on it.

Four people gather on the floor nearby and play the game once.

The winner of the round receives a card from each participant and writes down all participants' scores on the card (if there is a referee, the referee writes the scores on the card).

Move to a different floor and play again when 4 players gather (it is a foul to always throw on the same floor).

(It is a foul to always throw on the same floor.) Play the number of rounds indicated on the card.

The game ends for the person whose card is filled with scores.

The person in charge tallies the results and announces the high scorer.
