# Nine People – 8 Legs - 4 Hands

Group Size: 10+ participants
Difficulty: Quite easy
Materials: None
Duration: Approx. 10 minutes

Game Description: Teams of equal size are formed, with each team not exceeding ten members. The game leader then gives the players a task, such as overcoming a predetermined distance from point A to point B. This could look like the following, for example:

"Overcome the distance from A to B using only eight legs and four hands." Let's go! The players attempt to complete the distance according to the given task. This means only eight legs and four hands are allowed to touch the ground. How the teams manage this task is entirely up to them, but it should be done quickly, as they are playing against each other. Whichever team arrives first wins. If too many limbs touch the ground, the entire team must return to the starting point and try again. Once everyone has arrived, a new task can be given, and the return journey must be completed accordingly. The tasks must, of course, be adapted to the group size and age. The fewer people, the fewer limbs.
