# Massage Game - Farmer and Potato Field

A massage game for small to medium-sized groups.
Also excellent for younger children.

Everyone sits in a circle. There should be an even number of people (including the facilitator) so that everyone has a partner. If the number is odd, the facilitator can "assist" one of the pairs.
