# The Yes Game

Performing Game

One person calls out something, e.g., "We're all reading the newspaper," "We're all dancing in a circle," "We're all hopping like a frog."

The group shouts together "YES!!!!" and starts doing the activity. This continues until someone else calls out a new activity.
