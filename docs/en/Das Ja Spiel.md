> [!info] Brief Description
> A performance game where the group accepts suggestions with a collective "Yes!" and immediately implements them.

**Group Size**: 4-30 people
**Difficulty**: Easy
**Materials**: None
**Playtime**: 5-10 minutes

## **Game Description**:

Performance Game

One person calls out an action, e.g., "We're all reading the newspaper," "We're all dancing in a circle," "We're all hopping like a frog."

The group collectively shouts "YES!!!!" and begins to perform that activity. This continues until someone else calls out a new activity.
