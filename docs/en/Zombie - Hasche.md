# Zombie Tag

> [!info] Short Description
> "Zombie Tag" is a tag game for medium to very large groups where tagged players turn into zombies, creating a dynamic and exciting chase.

**Group Size**: Medium to extremely large
**Difficulty**: Easy
**Materials**: None
**Game Duration**: Approx. 10-15 minutes

## **Game Description**:

Depending on the group size, 1-5 taggers (zombies) are chosen.

The zombies extend their arms and move slowly and stiffly through the playing area.
❗ **Important: Zombies are not allowed to run!**

If a zombie tags another player, that person also turns into a zombie.

The playing area should be clearly defined and appropriate for the group size.

The game ends when all players have become zombies.

The game starts slowly, as the zombies are initially outnumbered and can only move slowly. However, as soon as the first players become zombies, a rapid self-dynamic develops.

This game is also suitable for very large groups (up to 100 children).
