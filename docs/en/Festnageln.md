> [!info] Brief Description
> A tag game for any group size that promotes speed and endurance, as players try to "nail" each other.

**Group Size**: Any
**Difficulty**: Medium
**Materials**: None
**Duration**: Approx. 15-20 minutes

## **Game Description**:

Everyone runs around the room, trying to tag each other's feet. If a foot is tagged, it is considered "nailed" to the floor and cannot be moved.

Even if both feet are nailed, players can still try to tag other players running by.

The last person still running freely wins.
