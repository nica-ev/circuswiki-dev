# Contribute to the Documentation – It's Easy!

Hello everyone! We're thrilled you want to help with our documentation. 😊 Here's a simple guide on how you can do it:

## What You'll Need

1.  **GitHub Account:**
    *   Create a free GitHub account if you don't have one yet: [https://github.com/join](https://github.com/join)
    *   We need this for everything to work smoothly.

2.  **GitHub Desktop:**
    *   Download and install GitHub Desktop: [https://desktop.github.com/](https://desktop.github.com/)
    *   This program makes working with Git easier, even if you're not very familiar with it.

## Let's Get Started!

1.  **Fork the Repository:**
    *   Go to our documentation area on GitHub (e.g., `nica-ev/docs`) and click the "Fork" button.
    *   This creates your own copy of the area where you can work without accidentally breaking anything. 😉

2.  **Get the Repository onto Your Computer:**
    *   Open GitHub Desktop.
    *   Click "File" -> "Clone repository...".
    *   Select your forked copy of the area from the list on GitHub.
    *   Choose a folder on your computer where you want to save the area.
    *   Click "Clone".
    *   Now you have a copy of the area on your computer.

3.  **(Optional) Create a New Branch:**
    *   In GitHub Desktop, click the "Current Branch" button (usually top left).
    *   Enter a new name for your working area (e.g., `new-page`, `fix-typo`).
    *   Click "Create branch".
    *   Branches help keep your changes separate. If something goes wrong, you can simply delete the branch.
    *   **Note:** Creating a new branch is optional, but it's a good practice for organizing your work.

4.  **Make Changes:**
    *   Use your text editor (e.g., Notepad, VS Code) to edit the files in the area on your computer.
    *   Here you can add text, correct errors, and so on.
    *   **Important:** Use Markdown for formatting (see below).

5.  **Save Your Changes:**
    *   In GitHub Desktop, go to the "Changes" tab to see your modified files.
    *   Write a brief summary in the "Summary" field.
    *   Click "Commit to `<branch-name>`" (or "Commit to main" if you didn't use a branch).
    *   Saving is like taking a snapshot of your work.

6.  **Upload Your Changes:**
    *   In GitHub Desktop, click "Push origin".
    *   This uploads your changes to your copy of the area on GitHub.

7.  **Submit Your Changes for Review:**
    *   In GitHub Desktop, click "Create Pull Request". This will open a page on GitHub.
    *   Review your changes there and click "Create Pull Request".
    *   A Pull Request is like a request to merge your changes into the main repository.

## Important to Know

*   **Markdown:** It's like a simple language for text. Here's a quick overview:
    *   `# Heading 1`
    *   `## Heading 2`
    *   `**Bold**`
    *   `*Italic*`
    *   `- List item`
    *   `[Link](https://www.example.com)`
*   **Commit Messages:** Write short messages for your saves so everyone knows what you did.
*   **Patience:** It might take a little practice at first. Just ask if anything is unclear!

Thanks for helping out! 🙌
