> [!info] Brief Description
> A dynamic warm-up game for any group size, combining movement, coordination, and fun.

**Group Size**: Any
**Difficulty**: Easy
**Materials**: None
**Duration**: Approx. 5-10 minutes

## **Game Description**:

Everyone stands in a circle and imitates the movements of the game leader.

| Text                                  | Movement                                                                  |
| :------------------------------------ | :------------------------------------------------------------------------ |
| In a big, big house                   | Stretch up as big as possible (arms spread wide)                          |
| Lived a tiny, tiny mouse              | Crouch down as small as possible on the floor                             |
| And in this big, big house            | Stretch up as big as possible (arms spread wide)                          |
| Lived a dog too                       | Hands and feet on the floor, bottom in the air (dog pose)                 |
| Very healthy                          | Stretch left leg up (maintain dog pose)                                   |
| Really very healthy                   | Stretch right leg up (maintain dog pose)                                  |
| And in this big, big house            | Stretch up as big as possible (arms spread wide)                          |
| Lived a snake too                     | Lie on your stomach (wiggle like a snake)                                 |
| The dog got scared, oh my             | Hands and feet on the floor, bottom in the air (scared dog pose)          |
| And ran away – to a new house         | Change places (quickly find a new spot in the circle)                     |

At the end of the story, everyone changes places so that they are back in a circle, but in a different spot.
The story is repeated, and told faster each time.
