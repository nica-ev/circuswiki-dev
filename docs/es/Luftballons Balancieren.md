# Balance de Globos

Un juego para grupos pequeños o grandes.

Materiales: Globos

Un juego sencillo para practicar los fundamentos del equilibrio.

Cada persona toma un globo e intenta mantenerlo el mayor tiempo posible sobre diferentes partes del cuerpo.
Por ejemplo: sobre la nariz, la cabeza, los dedos extendidos, el puño, etc.
