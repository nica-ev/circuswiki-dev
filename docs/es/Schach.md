# Ajedrez

Adecuado para grupos pequeños y medianos.

Se forman 2 equipos de igual tamaño.
Se delimita un campo de juego rectangular, y los dos equipos se colocan en los extremos opuestos.

Se aplican las siguientes reglas:
* Se juega por turnos.
* Solo puede mover una persona del equipo a la vez.
* Un movimiento consiste en saltar con ambos pies y aterrizar de forma segura con ambos pies. Un paso en falso o cualquier otro aterrizaje inestable/inseguro significa que se abandona el campo de juego.
* Solo se puede decidir quién salta del equipo mediante contacto visual; no se permite hablar ni gesticular.
* Si varias personas saltan al mismo tiempo, el director del juego decidirá quién debe abandonar el campo de juego.
* Se pueden "capturar" piezas del equipo contrario tocándolas con la mano después de aterrizar de forma segura. Estas piezas deben abandonar el campo de juego.
* Gana el equipo que primero llegue a la línea de fondo del equipo contrario o que haya "capturado" todas las piezas del equipo contrario.
