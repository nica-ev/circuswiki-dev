#  Aplauso con contacto visual

Juego de aplausos para cualquier tamaño de grupo:

Todas las personas se colocan en círculo.
El/la líder del grupo comienza y, mediante contacto visual, pasa un aplauso a cualquier persona del círculo. Esta persona busca el contacto visual con otra y se lo transmite...
El/la director/a del juego puede lanzar tantos aplausos adicionales como desee. Cuando un aplauso regresa al director/a del juego, este ya no se transmite más.
El juego termina cuando todos los aplausos han regresado al director/a del juego.
