# El Juego del Sí

Juego de representación

Una persona dice algo, por ejemplo: "todos leemos el periódico", "todos bailamos en círculo", "todos saltamos como una rana".

El grupo responde al unísono "¡¡¡SÍ!!!" y comienza a realizar esa actividad. Esto continúa hasta que otra persona propone una nueva actividad.
