# Juego de masajes - Granja y campo de patatas

Un juego de masajes para grupos pequeños y medianos.
También es ideal para niños pequeños.

Todos se sientan en círculo. Debe haber un número par de personas (incluido el director del juego) para que todos tengan pareja. Si no es posible, el director del juego puede "asistir" a una pareja.
