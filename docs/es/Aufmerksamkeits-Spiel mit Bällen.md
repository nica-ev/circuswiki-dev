# Juego de Atención con Pelotas

Juego para grupos pequeños y medianos.
Todas las personas corren libremente por un área de juego delimitada.
(ver también correr libremente / ejercicios de teatro / llenar el espacio)
Una persona tiene una pelota. Esta persona, mientras corre, establece contacto visual con otra persona y le lanza la pelota.

Importante: la persona a la que se le lanza la pelota debe estar relativamente cerca, y solo se le debe lanzar cuando se haya establecido contacto visual.

El nivel de dificultad se puede aumentar a voluntad incrementando el número de pelotas.
