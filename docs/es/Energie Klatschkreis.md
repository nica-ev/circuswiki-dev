# Círculo de Palmas Energético

Un juego de círculo para grupos pequeños o grandes.

Todos se ponen de pie en círculo y se pasan una palmada al vecino.
El objetivo es recibir esta palmada, darse la vuelta y pasarla, lo más rápido posible.
