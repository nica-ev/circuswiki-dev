# Taller Temático: Piratas

Especialmente para niños en edad preescolar, es recomendable integrar las disciplinas de forma temática. Un tema popular es, sin duda, "Piratas".

Maneras sencillas de incorporar el equilibrio sobre la cuerda son:

- cruzar un profundo barranco en busca del tesoro pirata

De manera similar, se pueden encontrar usos temáticos para (casi) todas las disciplinas.

- Artes aéreas: trepar por el barco en la jarcia
- Malabares con pañuelos: pañuelos rojos se usan como fuego en el que se asan malvaviscos/manzanas, estos se calientan y deben pasarse de mano en mano
