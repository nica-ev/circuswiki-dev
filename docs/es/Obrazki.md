# Imágenes

Actividad para grupos de aproximadamente 4-8 personas.

## Fase I

Los grupos tienen alternativamente 7 segundos para crear una "imagen" con sus cuerpos.

La consigna puede ser pública para todos o secreta para los demás grupos. En esta segunda opción, jugamos a las charadas grupales.

Ejemplos de consignas:

- maceta
- flor
- paraguas
- coche
- mesa
- peine
- batidora
- taza
- plato

## Fase II

Añadimos 3-7 segundos a la cuenta atrás. El objetivo y las reglas son los mismos, pero el grupo puede utilizar accesorios de circo.
