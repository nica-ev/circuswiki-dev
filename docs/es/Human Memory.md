# Memoria Humana

Juego para grupos medianos a grandes:

Dos personas salen de la sala.
El resto se agrupa en parejas y, juntas, inventan un movimiento y un sonido.
Los dos jugadores que están fuera regresan a la sala y ahora, por turnos, descubren las cartas de memoria vivientes nombrando a dos personas cada vez. Estas se levantan y presentan sus movimientos y sonidos.
Si forman una pareja idéntica, esta abandona el área de juego y se puede descubrir una segunda pareja.
Gana el jugador con más parejas.
