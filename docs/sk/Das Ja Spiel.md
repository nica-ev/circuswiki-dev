# Hra Áno

Dramatické hry

Jedna osoba niečo zvolá, napr. „Všetci čítame noviny“, „Všetci tancujeme v kruhu“, „Všetci skáčeme ako žaba“.

Skupina spoločne zvolá „ÁNO!!!!“ a začne vykonávať danú činnosť. Toto pokračuje, kým niekto iný nezvolá novú činnosť.
