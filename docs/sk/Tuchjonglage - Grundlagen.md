# Juchanie s vreckovkami – základy

Juchanie s vreckovkami je vďaka pomalému letu (kvôli vysokému odporu vzduchu) obzvlášť vhodné na osvojenie si základov juchania hádzaním.

Často sa dá v krátkom čase dosiahnuť úspech až po juchanie s 3 vreckovkami.

Pre začiatočníkov je tiež veľmi užitočné používať rôznofarebné vreckovky, aby získali lepší prehľad o dianí.
