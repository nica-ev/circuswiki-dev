# Pridajte sa k tvorbe dokumentácie – je to jednoduché!

Ahojte všetci! Sme radi, že nám chcete pomôcť s našou dokumentáciou. 😊 Tu je jednoduchý návod, ako na to:

## Čo potrebujete

1.  **Účet na GitHub:**
    *   Ak ešte nemáte, vytvorte si bezplatný účet na GitHub: [https://github.com/join](https://github.com/join)
    *   Potrebujeme ho, aby všetko fungovalo.

2.  **GitHub Desktop:**
    *   Stiahnite si a nainštalujte GitHub Desktop: [https://desktop.github.com/](https://desktop.github.com/)
    *   Tento program uľahčuje prácu s Git, aj keď s ním nemáte veľa skúseností.

## Ideme na to!

1.  **Skopírujte si úložisko (repository):**
    *   Prejdite do našej sekcie dokumentácie na GitHub (napr. `nica-ev/docs`) a kliknite na tlačidlo "Fork".
    *   Týmto si vytvoríte vlastnú kópiu úložiska, v ktorej môžete pracovať bez toho, aby ste niečo pokazili. 😉

2.  **Stiahnite si úložisko na svoj počítač:**
    *   Otvorte GitHub Desktop.
    *   Kliknite na "File" -> "Clone repository...".
    *   Zo zoznamu na GitHub vyberte svoju kópiu úložiska.
    *   Vyberte priečinok na svojom počítači, kam chcete úložisko uložiť.
    *   Kliknite na "Clone".
    *   Teraz máte kópiu úložiska na svojom počítači.

3.  **(Voliteľné) Vytvorte si nový pracovný priestor (branch):**
    *   V GitHub Desktop kliknite na tlačidlo "Current Branch" (zvyčajne vľavo hore).
    *   Zadajte nový názov pre svoj pracovný priestor (napr. `nova-stranka`, `opravit-chybu`).
    *   Kliknite na "Create branch".
    *   Pracovné priestory vám pomôžu oddeliť vaše zmeny. Ak sa niečo pokazí, môžete pracovný priestor jednoducho zmazať.
    *   **Poznámka:** Vytvorenie nového pracovného priestoru je voliteľné, ale je to dobrý spôsob, ako si organizovať svoje zmeny.

4.  **Vykonajte zmeny:**
    *   Použite svoj textový editor (napr. Notepad, VS Code) na úpravu súborov v úložisku na svojom počítači.
    *   Tu môžete pridávať texty, opravovať chyby a podobne.
    *   **Dôležité:** Na formátovanie používajte Markdown (pozri nižšie).

5.  **Uložte zmeny:**
    *   V GitHub Desktop v záložke "Changes" uvidíte svoje upravené súbory.
    *   Do poľa "Summary" napíšte krátky popis zmien.
    *   Kliknite na "Commit to `<branch-name>`" (alebo "Commit to main", ak ste nepoužili pracovný priestor).
    *   Uloženie je ako vytvorenie medzizastávky vašej práce.

6.  **Nahrajte zmeny:**
    *   V GitHub Desktop kliknite na "Push origin".
    *   Týmto sa vaše zmeny nahrajú do vašej kópie úložiska na GitHub.

7.  **Odošlite zmeny na kontrolu:**
    *   V GitHub Desktop kliknite na "Create Pull Request". Potom sa otvorí stránka na GitHub.
    *   Skontrolujte tam svoje zmeny a kliknite na "Create Pull Request".
    *   Pull Request je ako žiadosť o začlenenie vašich zmien do hlavného úložiska.

## Dôležité informácie

*   **Markdown:** Je to ako jednoduchý jazyk na písanie textov. Tu je krátky prehľad:
    *   `# Nadpis 1`
    *   `## Nadpis 2`
    *   `**Tučné písmo**`
    *   `*Kurzíva*`
    *   `- Zoznam`
    *   `[Odkaz](https://www.example.com)`
*   **Správy pri ukladaní:** Píšte krátke správy k svojim uloženiam, aby každý vedel, čo ste urobili.
*   **Trpezlivosť:** Na začiatku to možno bude chvíľu trvať. Ak vám niečo nie je jasné, pokojne sa opýtajte!

Ďakujeme, že pomáhate! 🙌
