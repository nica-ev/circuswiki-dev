# Quat Props 
 Spoločnosť Quat Props, založená Craigom Quatom, je medzinárodná iniciatíva zameraná na podporu prístupnosti a inklúzie prostredníctvom žonglovania. Vývojom inovatívnych nástrojov, ako je napríklad Juggle Board, tento projekt nanovo definuje žonglovanie ako prostriedok na vzdelávanie, terapiu a sociálne začlenenie, nielen ako formu vystúpenia. Jeho pedagogický rámec zdôrazňuje funkčnú hru, adaptabilitu a emocionálne učenie, čím umožňuje rôznym komunitám využívať žonglovanie ako cestu k sebaregulácii, spolupráci a tvorivému vyjadreniu.
