# 1, 2, 3

Gioco per qualsiasi dimensione di gruppo:

Si formano delle coppie.

**1ª fase:** I partner si mettono uno di fronte all'altro e contano alternandosi 1, 2, 3 (Max: 1, Linda: 2, Max: 3, Linda: 1, Max: 2...).
**2ª fase:** Invece di dire 1, si battono le mani (Max: batte le mani, Linda: 2, Max: 3, Linda: batte le mani, Max: 2...).
**3ª fase:** Al posto del 2, si salta sul posto (Max: batte le mani, Linda: salta, Max: 3, Linda: batte le mani, Max: salta, Linda: 3...).
**4ª fase:** Al posto del 3, si fa un giro su se stessi (Max: batte le mani, Linda: salta, Max: gira su se stesso, Linda: batte le mani...).

Le fasi possono poi essere smantellate a ritroso, fino a tornare al conteggio iniziale.
