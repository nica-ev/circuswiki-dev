# Il Fotografo

Gioco teatrale / circense-pedagogico per gruppi piccoli o medi.

Il gruppo si muove liberamente nello spazio di gioco; a un segnale, il compito è quello di rappresentare un tema (il movimento viene congelato) attorno al centro del palco.
L'immagine creata viene "fotografata".

Dopo alcuni round, ci si riunisce per analizzare le immagini: composizione dell'immagine, distribuzione nello spazio, visibilità delle persone, ecc.

Temi possibili: fiabe, circo, pulizie, vita d'ufficio, fare la spesa, parco giochi, in spiaggia, ecc.
