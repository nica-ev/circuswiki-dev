# Robot

Robot
Gioco di fiducia per qualsiasi dimensione di gruppo:

Si formano coppie di due persone.
Una persona è il robot, che deve essere guidato attraverso la stanza. Chi fa il robot chiude gli occhi e si lascia guidare dalla persona che sta dietro. Quest'ultima appoggia le mani sulle spalle del proprio robot e cerca di guidarlo con cautela attraverso la stanza, senza urtare le altre coppie.
Se due coppie si incontrano, i robot possono essere scambiati con un altro "capo robot".
Successivamente, i ruoli vengono invertiti.
