# Обмін місцями через зоровий контакт

Гра в колі для невеликих та середніх груп.
Усі стоять у колі. Спробуйте встановити зоровий контакт з іншою людиною та підтвердити цей контакт легким кивком голови. Коли ви встановили контакт таким чином, обміняйтеся місцями, просто пройшовши через центр кола, таким чином змінивши своє місце з людиною, з якою ви встановили контакт.

Усі грають одночасно – це тренує увагу та комунікацію. Потрібно бути уважним, щоб помітити, хто дивиться на вас і хоче обмінятися з вами місцями.

Як розширення, можна поступово зменшувати необхідний контакт – спочатку ще потрібен кивок головою, це поступово вдосконалюється, доки лише зоровий контакт не вирішуватиме, чи обмінюватися місцями, чи ні.

# Варіація

Варіація полягає у зменшенні необхідних сигналів для успішного встановлення контакту.
Зрештою, достатньо простого погляду без додаткових фізичних сигналів, щоб встановити та підтвердити контакт.
