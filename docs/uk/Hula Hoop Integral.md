# Хулахуп Інтеграл

Хулахуп Інтеграл — це педагогічний та мистецький проєкт, що зародився в Латинській Америці. Він досліджує обруч як інструмент для навчання, самовираження та соціальних змін. Його підхід поєднує гру, рух та інклюзивність, пропонуючи доступні можливості для людей будь-якого віку та походження. Через тренінги, майстер-класи та громадські акції проєкт сприяє розвитку співпраці та чутливих методологій, зосереджених на тілі, творчості та різноманітності.
