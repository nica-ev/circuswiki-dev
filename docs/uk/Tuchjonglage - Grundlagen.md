# Жонглювання хустками — Основи

Жонглювання хустками чудово підходить для вивчення основ жонглювання кидками, оскільки вони мають повільний політ (через високий опір повітря).

Часто успіху можна досягти за дуже короткий час, аж до жонглювання трьома хустками.

Для новачків також дуже корисно використовувати хустки різних кольорів, щоб краще орієнтуватися в процесі.
