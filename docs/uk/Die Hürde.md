# Бар'єр

**Кількість гравців:** від 4 до 20 учасників
**Складність:** середня
**Матеріал:** мотузка
**Тривалість гри:** 5–10 хвилин

**Опис гри:**
Між двома стійкими опорами (стовпами, деревами або чимось подібним) натягують мотузку. Висоту натягування мотузки ведучий гри має добре розрахувати. Один гравець повинен мати змогу перестрибнути через мотузку. Адже мета гри — подолати мотузку, не торкнувшись її та не пролізши під нею. Це означає, що гравці повинні допомагати один одному перебратися через мотузку, піднімаючи, несучи, будуючи піраміди або використовуючи техніку "драбинки розбійників". Кожна група знайде свій власний спосіб переправити всіх через мотузку. Якщо хтось із гравців торкається мотузки, вся команда має повернутися на початковий бік.
