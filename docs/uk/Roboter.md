# Робот

Робот
Гра на довіру для будь-якого розміру групи:

Дві особи об'єднуються в пари.
Одна людина — це робот, якого потрібно провести через кімнату. Він заплющує очі й дозволяє своєму партнерові позаду керувати собою. Той кладе руки на плечі свого робота і намагається обережно провести його через кімнату, не зіткнувшись з іншими парами.
Якщо дві пари зустрічаються, роботи можуть бути обміняні з іншим провідником робота.
Після цього ролі міняються.
