# **Odskocznia Studio**

Odskocznia Studio пропонує динамічні цирково-педагогічні майстер-класи, що поєднують тіло та розум через жонглювання, балансування та акробатику. Завдяки широкому вибору реквізиту — включно з м'ячами, хустками, обручами, дияболо, рола-болами, ходулями, моноциклами та іншим — майстер-класи створюють атмосферу радісної, усвідомленої гри.

Ці захопливі заняття розроблені для дітей, дорослих, шкіл, підприємств та людей похилого віку, сприяючи розвитку координації, концентрації, креативності та моторики. В Odskocznia цирк стає інструментом для навчання, самовираження та спілкування, доступним для всіх поколінь.
