# Циркова студія Woesh

Циркова студія Woesh — це молодіжна циркова організація з Брюгге та Остенде, яка надихає громади по всій Західній Фландрії. Ми віримо в силу цирку як засобу, що об'єднує людей — незалежно від віку, походження, досвіду чи таланту.

Woesh приділяє особливу увагу особам з особливими потребами та розвивається як відкритий простір для навчання, де мистецькі експерименти, освіта та інклюзія йдуть пліч-о-пліч.
Ми робимо це не самі: ми тісно співпрацюємо з широкою мережею партнерів.
