# Пальчикові бої

Гра для будь-якої кількості учасників:

Учасники діляться на пари.
Двоє людей беруться за руки. Потім роблять крок назад, витягують по одному вказівному пальцю і стають у "бойову стійку".
За командою вони намагаються торкнутися пальцем живота партнера.
Хто перший торкнеться іншого, той виграє гру.
