# Спікі-дейтинг

- 2 кола однакового розміру, що відповідають кількості учасників
- 1 зовнішнє коло, 1 внутрішнє коло
- учасники стоять парами один навпроти одного (кожен з внутрішнього кола навпроти когось із зовнішнього)
- учасники зовнішнього кола дивляться всередину, учасники внутрішнього кола – назовні

Далі відбувається наступне:
- учасники внутрішнього кола називають своє ім'я партнеру із зовнішнього кола та діляться якоюсь інформацією про себе.
- потім учасники внутрішнього кола пересуваються на одну особу за годинниковою стрілкою.

Коли всі пройшли повне коло:
- зовнішнє та внутрішнє кола міняються місцями.

Після цього роздаються аркуші паперу з іменами учасників та ручки, і кожен записує все, що пам'ятає, на відповідних аркушах.
