# Сортування в групі

Кооперативна гра для малих та середніх груп.

**Реквізит:** Стільці або табурети тощо для кожної особи.

Стільці розставляються по колу з невеликою відстанню між ними, так, щоб можна було зручно пересісти з одного стільця на інший.

Кожна людина сідає на стілець. Завдання групи — пересортуватися так, щоб ніхто не торкнувся підлоги.

Сортування може відбуватися, наприклад, за іменем, зростом, віком тощо.

Для ускладнення можна заборонити вербальне спілкування.
Розстановка стільців у ряд замість кола також ускладнює завдання.
