# Король повітря

Гра на довіру для середніх груп:

Обирається король. Він лягає на землю, а його піддані збираються навколо нього. Потім його піднімають. Якщо він надійно лежить на руках своїх підданих, король може обережно рухатися: наприклад, піднятися, по черзі підняти ноги в повітря або навіть зробити перекид. Піддані мають уважно стежити за його рухами та підтримувати свого короля.
Наприкінці його обережно опускають на землю.
