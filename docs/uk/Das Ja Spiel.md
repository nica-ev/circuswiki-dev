# Гра «Так»

Ігрове дійство

Одна людина пропонує якусь дію, наприклад: «Усі читаємо газету», «Усі танцюємо в колі», «Усі стрибаємо, як жаби».

Група спільно вигукує: «ТАК!!!!» і починає виконувати цю дію. Це триває доти, доки хтось інший не запропонує нову дію.
