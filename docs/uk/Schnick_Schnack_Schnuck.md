# Шнік-шнак-шнук

Гра для знайомства для малих і дуже великих груп.

Основа гри — "Камінь, ножиці, папір" (в українській версії — "Шнік, шнак, шнук"). Існують лише три стани: камінь б'є ножиці, ножиці ріжуть папір, папір огортає камінь.

Усі учасники вільно рухаються кімнатою. Коли двоє людей зустрічаються, вони грають у "Шнік, шнак, шнук". Той, хто програє, чіпляється переможцю на плечі та починає скандувати його ім'я. Ця маленька "змійка" продовжує рухатися кімнатою, доки не зустріне когось наступного і знову грає.

Наприкінці гри залишається лише одна "змійка", на чолі якої йде переможець, а всі інші скандують його ім'я.
