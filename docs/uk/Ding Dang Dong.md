# Дзінь-Дзінь-Дон

Плескавка для 2 осіб.

Текст:
«О, повітряна куля, цукерка-карамелька.
Всі мавпи та жирафи роблять
Дзінь-Дзінь-Дон
Всі свині без ніг,
Всі кози без крил
роблять «Меее»»

Далі текст з рухами:

«О *(руки перед ротом, складені як рупор для вигуку)*
Повітряна куля, цукерка-карамелька, всі мавпи та жирафи роблять
*(руки ритмічно плескають одна об одну або об руки партнера, чергуючись)*
Дзінь *(рука торкається голови)*
Дзінь *(рука торкається стегна)*
Дон *(рука торкається стопи)*
Всі свині без ніг, всі кози без крил
*(руки ритмічно плескають одна об одну або об руки партнера, чергуючись)*
роблять «Меее» *(руки біля вух, долоні відкриті до партнера, великі пальці торкаються скронь)*»
