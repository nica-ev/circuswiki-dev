# Образи

Активність для груп приблизно 4-8 осіб.

## Етап I

Групи по черзі мають по 7 секунд, щоб створити «образ» зі своїх тіл.

Завдання може бути явним для всіх або таємним для інших груп. У другому варіанті граємо в групові шаради.

Приклади завдань:

- горщик
- квітка
- парасолька
- автомобіль
- стіл
- гребінець
- міксер
- чашка
- тарілка

## Етап II

Додаємо 3-7 секунд до відліку. Мета та правила такі самі, але група може використовувати цирковий реквізит.
