# Корівник

Гра для середніх та великих груп:

Утворюються групи по 3 особи. Дві особи формують "корівник" (витягують руки вгору і з'єднують долоні — утворюючи дах), а під цим "дахом" стає третя особа — це "корова".
Одна особа залишається поза групою. Ця особа намагається зайняти місце в одній із груп. Для цього вона може використовувати 3 команди: "Корова", "Корівник" або "Корівник-Корова".

*   **"Корова"**: Всі "корови" повинні якомога швидше вибігти зі своїх "корівників" і знайти нове місце. За цей час особа, яка залишилася поза групою, може швидко зайняти місце "корови" в одному з "корівників". "Корова", яка залишилася без місця, може назвати наступну команду.
*   **"Корівник"**: "Корівники" повинні роз'єднатися і знову утворити "дах" над іншою "коровою" разом з іншою особою.
*   **"Корівник-Корова"**: Всі групи по 3 особи розпадаються, і учасники шукають собі нові місця. Тут також дозволяється мінятися ролями: "корови" можуть стати "корівниками", а "корівники" — "коровами".
