# Піратська вітальна гра

Тематична гра для груп будь-якого розміру. Наведений нижче текст співається та супроводжується відповідними жестами / рухами.

"**Гей, пірате, ти виглядаєш зухвало.**
*[ Вказати на іншого пірата ]*
**Витягни-но свій абордажний гак.**
*[ Зігнути вказівні пальці, показати один на одного і зачепити їх ]*
**Гак хитати, хитати, хитати, хитати.**
[ Зігнуті вказівні пальці хитають ]*
**І дерев'яною ногою трусити, трусити, трусити, трусити.**
[ Нахилитися вперед, підняти одну ногу, схопити один одного за підняту ногу і трусити її ]*
**А потім далі кульгати, кульгати, кульгати, кульгати.**
[ Відпустити ноги і відкульгати ]*
**І наступному махати, махати, махати, махати.**
[ Прицілитися в наступного пірата і помахати йому ]*
"
