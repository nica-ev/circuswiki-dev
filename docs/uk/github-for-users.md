# Долучайтеся до документування – це просто!

Привіт усім! Ми раді, що ви хочете допомогти з нашим документуванням. 😊 Ось проста інструкція, як це зробити:

## Що вам знадобиться

1.  **Обліковий запис GitHub:**
    *   Створіть безкоштовний обліковий запис GitHub, якщо у вас його ще немає: [https://github.com/join](https://github.com/join)
    *   Він потрібен для коректної роботи.

2.  **GitHub Desktop:**
    *   Завантажте та встановіть GitHub Desktop: [https://desktop.github.com/](https://desktop.github.com/)
    *   Ця програма спрощує роботу з Git, навіть якщо ви не дуже добре з ним знайомі.

## Починаємо!

1.  **Створіть копію репозиторію (Fork):**
    *   Перейдіть до нашого розділу документування на GitHub (наприклад, `nica-ev/docs`) і натисніть кнопку "Fork".
    *   Це створить вашу власну копію розділу, де ви зможете працювати, нічого не зіпсувавши. 😉

2.  **Завантажте репозиторій на свій комп'ютер:**
    *   Відкрийте GitHub Desktop.
    *   Натисніть "File" -> "Clone repository...".
    *   Виберіть свою копію розділу зі списку на GitHub.
    *   Виберіть папку на своєму комп'ютері, куди ви хочете зберегти розділ.
    *   Натисніть "Clone".
    *   Тепер у вас є копія розділу на вашому комп'ютері.

3.  **(Необов'язково) Створіть нову робочу гілку:**
    *   У GitHub Desktop натисніть кнопку "Current Branch" (зазвичай у верхньому лівому куті).
    *   Введіть нову назву для вашої робочої гілки (наприклад, `нова-сторінка`, `виправити-помилку`).
    *   Натисніть "Create branch".
    *   Робочі гілки допомагають відокремлювати ваші зміни. Якщо щось піде не так, ви можете просто видалити цю гілку.
    *   **Пам'ятайте:** Створення нової робочої гілки є необов'язковим, але це гарна ідея для організації ваших змін.

4.  **Вносьте зміни:**
    *   Використовуйте текстовий редактор (наприклад, Notepad, VS Code), щоб редагувати файли в розділі на своєму комп'ютері.
    *   Тут ви можете додавати текст, виправляти помилки тощо.
    *   **Важливо:** Використовуйте Markdown для форматування (див. нижче).

5.  **Збережіть зміни:**
    *   У GitHub Desktop на вкладці "Changes" ви побачите свої змінені файли.
    *   Введіть коротке резюме у поле "Summary".
    *   Натисніть "Commit to `<branch-name>`" (або "Commit to main", якщо ви не використовували робочу гілку).
    *   Збереження – це як проміжний етап вашої роботи.

6.  **Завантажте зміни:**
    *   У GitHub Desktop натисніть "Push origin".
    *   Це завантажить ваші зміни до вашої копії розділу на GitHub.

7.  **Надішліть зміни на перевірку:**
    *   У GitHub Desktop натисніть "Create Pull Request". Це відкриє сторінку на GitHub.
    *   Перегляньте там свої зміни та натисніть "Create Pull Request".
    *   Pull Request – це як запит на включення ваших змін до основного розділу.

## Важливо знати

*   **Markdown:** Це проста мова для форматування тексту. Ось короткий огляд:
    *   `# Заголовок 1`
    *   `## Заголовок 2`
    *   `**Жирний текст**`
    *   `*Курсив*`
    *   `- Список`
    *   `[Посилання](https://www.example.com)`
*   **Повідомлення під час збереження:** Пишіть короткі повідомлення до своїх збережень, щоб усі знали, що ви зробили.
*   **Терпіння:** Спочатку може знадобитися трохи практики. Просто запитуйте, якщо щось незрозуміло!

Дякуємо за допомогу! 🙌
