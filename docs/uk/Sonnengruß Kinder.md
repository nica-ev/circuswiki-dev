# Привітання Сонця для дітей

Сонце встає (потягнутися)
Сонце сідає (нахилитися)
Воно будить одну ногу (Поза Воїна)
Інша прокидається (віджимання)

Воно будить гусінь (лягти на підлогу)
Воно будить змію (спертися на руки, прогнутися назад)
Воно будить собаку (Поза Собаки)
Це триває недовго

Інша нога назад (Поза Воїна в інший бік)
Сонце встає (потягнутися)
Яке щастя ([[Namaste]])
