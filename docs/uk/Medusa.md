# Медуза

Колові ігри для малих та середніх груп:

Усі стають у коло, опустивши голови донизу.
Ведучий рахує: "Раз-два-три!", після чого всі піднімають голови й дивляться в очі обраній людині.
Якщо погляди двох людей випадково зустрілися, вони "скам'яніли" одне для одного і театрально падають на землю.
Перемагають двоє останніх людей, що залишилися стояти в колі.
