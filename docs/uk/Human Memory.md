# Людська пам'ять

Гра для середніх та великих груп:

Двоє людей виходять з кімнати.
Решта учасників об'єднуються в пари та разом вигадують один рух і один звук.
Двоє гравців, які були зовні, повертаються до кімнати і по черзі "відкривають" живі картки меморі, називаючи імена двох людей. Ці люди встають і демонструють свій рух та звук.
Якщо пари збіглися (однакові рухи та звуки), ця пара залишає ігровий простір, і можна відкривати наступну пару.
Перемагає гравець, який зібрав найбільше пар.
