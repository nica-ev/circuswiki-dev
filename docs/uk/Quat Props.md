# Quat Props
Заснована Крейгом Кватом, Quat Props — це міжнародна ініціатива, присвячена розширенню доступності та інклюзивності через жонглювання. Розробляючи інноваційні інструменти, такі як Juggle Board, проєкт переосмислює жонглювання як засіб для освіти, терапії та соціальної взаємодії, а не лише як виступ. Його педагогічна основа наголошує на функціональній грі, адаптивності та емоційному навчанні, дозволяючи різноманітним спільнотам використовувати жонглювання як шлях до саморегуляції, співпраці та творчого самовираження.
