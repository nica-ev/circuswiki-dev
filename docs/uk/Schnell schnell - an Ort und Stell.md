# Швидко, швидко – на місце!

Реакційна гра для груп середнього розміру.

Ведучий стоїть посередині квадрата. Гравці стоять групами однакового розміру, розподілені по сторонах квадрата.

Ведучий обертається (на 90, 180, 270, 360 градусів) – тепер усі мають знову вишикуватися / помінятися місцями так, щоб відновити початкову ситуацію.
Коли група повністю зібралася, вона вигукує: «Швидко, швидко – на місце!»
