# Слалом у шерензі

Розминка для невеликих та середніх груп. Багато простору для варіацій.

Формуються невеликі групи по 3-5 осіб. Учасники кожної групи стають один за одним у шеренгу. Між ними має бути достатньо місця, щоб вільно проходити.

Групи мають стояти на такій відстані одна від одної, щоб не заважати.
Далі описано різні варіанти виконання.

Слалом:
Остання людина в шерензі починає бігти змійкою навколо людей, що стоять перед нею, доки не дістанеться до голови шеренги. Там вона зупиняється.
Передостання людина починає бігти навздог*он, щойно вона стає останньою в шерензі.

Високо / Низько:
Учасники шеренги по черзі стоять то прямо, розставивши ноги, то присідають якомога нижче. Останній у шерензі знову починає: крізь розставлені ноги проповзають, через присілу людину перестрибують.

Собачий тунель:
Кожна людина в групі стає в позу йоги "Собака" – ступні та долоні на підлозі, ноги випрямлені, сідниці підняті так, щоб тіло утворювало трикутник з підлогою.
Кожна людина повертається так, щоб утворився тунель (всі повертаються праворуч і приймають цю позицію).
Останній у шерензі проповзає крізь цей тунель, а опинившись з іншого боку, знову приймає позицію "Собака".

Віджимання:
Кожна людина в групі повертається праворуч і приймає позицію для віджимань, руки можуть залишатися випрямленими. Останній у шерензі переступає через інших; опинившись з іншого боку, він знову приймає позицію для віджимань.
