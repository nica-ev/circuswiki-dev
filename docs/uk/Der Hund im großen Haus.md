> [!info] Короткий опис
> Оповідлива розігрівна гра, під час якої група відтворює коротку історію відповідними рухами.

**Кількість учасників**: 5-30 осіб
**Складність**: Легка
**Матеріали**: Не потрібні
**Тривалість гри**: Приблизно 5-10 хвилин

## **Опис гри**:

Усі учасники стають у коло і повторюють рухи ведучого.

| Текст                                  | Рух                                                                       |
| :------------------------------------ | :------------------------------------------------------------------------ |
| У великому-великому домі               | Стати дуже великим (широко розвести руки)                                |
| Жила маленька-маленька мишка           | Присісти на підлогу, ставши дуже маленьким                               |
| І в цьому великому-великому домі       | Стати дуже великим (широко розвести руки)                                |
| Жив також собака                      | Поставити руки й ноги на підлогу, піднявши таз (поза собаки)             |
| Дуже здоровий                         | Підняти ліву ногу (залишаючись у позі собаки)                             |
| Справді дуже здоровий                 | Підняти праву ногу (залишаючись у позі собаки)                            |
| І в цьому великому-великому домі       | Стати дуже великим (широко розвести руки)                                |
| Жила також змія                       | Лягти на живіт (імітуючи рухи змії)                                      |
| Собаці стало страшно                  | Поставити руки й ноги на підлогу, піднявши таз (страшна поза собаки)    |
| І він утік – у новий дім              | Змінити місце (швидко знайти нове місце в колі)                          |

Наприкінці історії учасники змінюють місце так, щоб знову утворити коло, але вже в іншому місці.
Історію повторюють, розповідаючи її щоразу швидше.
