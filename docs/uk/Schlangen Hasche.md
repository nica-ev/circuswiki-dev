# Змійка-квач

**Кількість гравців**: від 6 учасників
**Складність**: проста
**Матеріал**: не потрібен
**Тривалість гри**: 5-10 хвилин

**Опис гри**:
Визначається один ведучий ("квач"). Він повзає по землі, як змія, і намагається торкнутися ніг інших гравців.
Якщо ведучий торкнувся когось, ця людина також стає "змією".
Перемагає той, хто залишиться останнім, стоячи на обох ногах.
