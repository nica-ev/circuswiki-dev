> [!info] Короткий опис
> Парна вправа, під час якої простий лічильний ритм поступово замінюється рухами.

**Розмір групи**: від 2 осіб
**Складність**: проста
**Матеріал**: жодного
**Тривалість гри**: 5-10 хвилин

## **Опис гри**:

Гра для будь-якого розміру групи.

Утворюються пари.

**1. Раунд:** Партнери стають один навпроти одного і по черзі рахують 1, 2, 3 (Макс: 1, Лінда: 2, Макс: 3, Лінда: 1, Макс: 2...).
**2. Раунд:** Замість того, щоб говорити «1», тепер плескають у долоні (Макс: плескає, Лінда: 2, Макс: 3, Лінда: плескає, Макс: 2...).
**3. Раунд:** Замість «2» тепер стрибають на місці (Макс: плескає, Лінда: стрибає, Макс: 3, Лінда: плескає, Макс: стрибає, Лінда: 3...).
**4. Раунд:** Замість «3» роблять один оберт навколо своєї осі (Макс: плескає, Лінда: стрибає, Макс: обертається, Лінда: плескає...).

Після цього раунди можна проходити у зворотному порядку, доки не повернетеся до початкового лічби.
