# Схрещені руки

Реакційна гра в колі для малих та середніх груп.

Підготовка:
Усі учасники сидять у колі, поклавши обидві руки перед собою на підлогу.
Тепер позиції рук обмінюються з сусідами праворуч і ліворуч так, щоб руки перехрестилися з руками сусідів.

Хід гри:
По черзі учасники плескають по підлозі однією рукою (один раз). При цьому враховується послідовність рук на підлозі, а не послідовність учасників.
Якщо плеснути двічі поспіль швидко, напрямок гри змінюється. Це може зробити будь-хто будь-коли.
Якщо учасник рухає рукою не в тому місці або надто довго вагається, ця рука вибуває з гри.

Переможцями стають останні два учасники.
