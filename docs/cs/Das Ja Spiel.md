# Hra „Ano“

Dramatické hry

Jedna osoba něco zvolá, např. „Všichni čteme noviny“, „Všichni tančíme v kruhu“, „Všichni skáčeme jako žába“.

Skupina společně zvolá „ANO!!!!“ a začne tuto činnost provádět. To pokračuje, dokud někdo jiný nezvolá novou činnost.
