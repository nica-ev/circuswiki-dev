# Lasery

Reakční hra pro malé až středně velké skupiny.

Jeden hráč je „nositelem laseru“ – stojí čelem ke zbytku skupiny. Pomalu pohybuje rukama, jako by držel laserový meč (seká doprostřed, zprava doleva ve výši hlavy atd.).

Ostatní hráči reagují jako rtuť – když se „neviditelný laser“ přiblíží, skupina se v daném místě rychle rozplyne, aby se následně stejně rychle opět spojila do homogenní celku.

Důležité jsou pomalé pohyby nositele laseru, aby ostatní měli čas reagovat.
