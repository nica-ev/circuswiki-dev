# Zapojte se do dokumentace – Je to snadné!

Ahoj všichni! Jsme rádi, že nám chcete pomoct s naší dokumentací. 😊 Zde je jednoduchý návod, jak na to:

## Co potřebujete

1.  **Účet na GitHubu:**
    *   Pokud ještě nemáte, vytvořte si bezplatný účet na GitHubu: [https://github.com/join](https://github.com/join)
    *   Potřebujeme ho, aby vše fungovalo.

2.  **GitHub Desktop:**
    *   Stáhněte si a nainstalujte GitHub Desktop: [https://desktop.github.com/](https://desktop.github.com/)
    *   Tento program usnadňuje práci s Gitem, i když s ním nejste moc obeznámeni.

## Jdeme na to!

1.  **Zkopírujte si repozitář:**
    *   Přejděte do naší sekce dokumentace na GitHubu (např. `nica-ev/docs`) a klikněte na tlačítko "Fork".
    *   Tím si vytvoříte vlastní kopii sekce, ve které můžete pracovat, aniž byste něco pokazili. 😉

2.  **Stáhněte si repozitář na svůj počítač:**
    *   Otevřete GitHub Desktop.
    *   Klikněte na "File" -> "Clone repository...".
    *   Vyberte svou kopii sekce ze seznamu na GitHubu.
    *   Vyberte složku na svém počítači, kam chcete sekci uložit.
    *   Klikněte na "Clone".
    *   Nyní máte kopii sekce na svém počítači.

3.  **(Volitelné) Vytvořte si nový pracovní prostor:**
    *   V GitHub Desktop klikněte na tlačítko "Current Branch" (obvykle vlevo nahoře).
    *   Zadejte nový název pro svůj pracovní prostor (např. `nova-stranka`, `oprava-chyby`).
    *   Klikněte na "Create branch".
    *   Pracovní prostory pomáhají oddělit vaše změny. Pokud se něco pokazí, můžete pracovní prostor jednoduše smazat.
    *   **Poznámka:** Vytvoření nového pracovního prostoru je volitelné, ale je to dobrý způsob, jak si uspořádat změny.

4.  **Proveďte změny:**
    *   Použijte svůj textový editor (např. Poznámkový blok, VS Code) k úpravě souborů v sekci na svém počítači.
    *   Zde můžete přidávat texty, opravovat chyby atd.
    *   **Důležité:** Pro formátování použijte Markdown (viz níže).

5.  **Uložte změny:**
    *   V GitHub Desktop uvidíte v záložce "Changes" své upravené soubory.
    *   Do pole "Summary" napište krátký popis.
    *   Klikněte na "Commit to `<název-vašeho-pracovního-prostoru>`" (nebo "Commit to main", pokud jste nepoužili pracovní prostor).
    *   Uložení je jako vytvoření mezikroku vaší práce.

6.  **Nahrajte změny:**
    *   V GitHub Desktop klikněte na "Push origin".
    *   Tím se vaše změny nahrají do vaší kopie sekce na GitHubu.

7.  **Odešlete změny k revizi:**
    *   V GitHub Desktop klikněte na "Create Pull Request". Poté se otevře stránka na GitHubu.
    *   Zde si zkontrolujte své změny a klikněte na "Create Pull Request".
    *   Pull Request je jako žádost o začlenění vašich změn do hlavní sekce.

## Důležité informace

*   **Markdown:** Je to jako jednoduchý jazyk pro texty. Zde je krátký přehled:
    *   `# Nadpis 1`
    *   `## Nadpis 2`
    *   `**Tučně**`
    *   `*Kurzíva*`
    *   `- Seznam`
    *   `[Odkaz](https://www.example.com)`
*   **Zprávy při ukládání:** Pište krátké zprávy ke svým uložením, aby každý věděl, co jste udělali.
*   **Trpělivost:** Zpočátku to možná bude vyžadovat trochu cviku. Pokud vám něco není jasné, zeptejte se!

Děkujeme za vaši pomoc! 🙌
