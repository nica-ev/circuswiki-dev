# Robot

Robot
Důvěrná hra pro jakoukoli velikost skupiny:

Dvojice se spojí do dvojic.
Jedna osoba je robot, který musí být proveden místností. Zavře oči a nechá se vést osobou za sebou. Tato osoba položí ruce na ramena svého robota a snaží se ho opatrně provést místností, aniž by narazil do jiných dvojic.
Pokud se dvě dvojice setkají, mohou se roboti vyměnit s jiným robotickým vůdcem.
Poté se role vymění.
