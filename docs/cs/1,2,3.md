# 1, 2, 3

Hra pro libovolný počet hráčů:

Vytvoří se dvojice.

**1. kolo:** Partneři si stoupnou naproti sobě a střídavě počítají 1, 2, 3 (Max: 1, Linda: 2, Max: 3, Linda: 1, Max: 2 …).
**2. kolo:** Místo čísla 1 se nyní tleskne (Max: tleskne, Linda: 2, Max: 3, Linda: tleskne, Max: 2 …).
**3. kolo:** Místo čísla 2 se nyní na místě poskočí (Max: tleskne, Linda: poskočí, Max: 3, Linda: tleskne, Max: poskočí, Linda: 3 …).
**4. kolo:** Místo čísla 3 se provede otočka kolem vlastní osy (Max: tleskne, Linda: poskočí, Max: otočí se, Linda: tleskne …).

Kola lze následně opět rozkládat odzadu dopředu, dokud se nedojde zpět k původnímu počítání.
