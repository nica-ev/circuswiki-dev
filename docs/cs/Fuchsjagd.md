# Liščí hon

> [!info] Stručný popis
> Jednoduchá a dynamická honička pro malé až středně velké skupiny, jejímž cílem je získat liščí ocas ostatních a přitom se nenechat chytit.

**Velikost skupiny**: Malá až střední
**Obtížnost**: Lehká
**Materiál**: Pro každého účastníka šátek (jako „liščí ocas“)
**Délka hry**: Cca 10–15 minut

## **Popis hry**:

Každý účastník si zastrčí šátek (jako „liščí ocas“) dozadu do kalhot. Pouze lovec (liška) nemá liščí ocas.

Lovec se nyní snaží někomu chytit liščí ocas. Pokud se mu to podaří, ten, komu byl ocas chycen, se stává novým lovcem.
