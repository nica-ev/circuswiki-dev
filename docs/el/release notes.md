>[!info]
>Αυτές οι Σημειώσεις Έκδοσης παρέχουν μόνο μια γενική επισκόπηση. Μικρές αλλαγές (όπως μεμονωμένες νέες σελίδες, τροποποιήσεις υπάρχοντος περιεχομένου) δεν αναφέρονται όλες. Ωστόσο, μπορούν να παρακολουθηθούν λεπτομερώς στο ιστορικό του αποθετηρίου.

>[!info]- **Έκδοση:** v0.03 - **Ημερομηνία Έκδοσης**: 11 Μαρτίου 2025
>**Περιεχόμενο**
>- Προστέθηκαν περιγραφές παιχνιδιών που έλειπαν
>
>**Τεχνικά**
>- Προστέθηκε Favicon + Λογότυπο
>- Ανασχεδιασμός UI
>- Η πλοήγηση πρώτου επιπέδου βρίσκεται πλέον στην κεφαλίδα της σελίδας, ενώ η δεξιά γραμμή πλοήγησης προσαρμόζεται ανάλογα με τα συμφραζόμενα
>- Οι πίνακες μπορούν να ταξινομηθούν κάνοντας κλικ στις κεφαλίδες τους
>
>**Διορθώθηκαν**
>- Οι ετικέτες λειτουργούν ξανά
