# Ζογκλερικά με Μαντήλια - Βασικές Αρχές

Το ζογκλερικό με μαντήλια είναι ιδανικό για την εκμάθηση των βασικών αρχών της ρίψης και του ζογκλερικού, λόγω της αργής κίνησης πτήσης τους (λόγω της μεγάλης αντίστασης του αέρα που προκαλούν τα μαντήλια).

Συχνά, η επιτυχής εκμάθηση έως και του ζογκλερικού με 3 μαντήλια μπορεί να επιτευχθεί σε πολύ σύντομο χρονικό διάστημα.

Επιπλέον, για τους αρχάριους, είναι πολύ χρήσιμο να χρησιμοποιούν μαντήλια διαφορετικών χρωμάτων για να έχουν καλύτερη επισκόπηση του τι συμβαίνει.
