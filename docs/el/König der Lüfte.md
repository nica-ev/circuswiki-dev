# Βασιλιάς των Ουρανών

Παιχνίδι εμπιστοσύνης για μεσαίες ομάδες:

Επιλέγεται ένας βασιλιάς. Αυτός ξαπλώνει ανάσκελα στο έδαφος και ο λαός του συγκεντρώνεται γύρω του. Τώρα, τον σηκώνουν ψηλά. Αν είναι ασφαλής στα χέρια του λαού του, ο βασιλιάς μπορεί να κινηθεί προσεκτικά, π.χ. να σηκωθεί, να σηκώσει τα πόδια του ένα-ένα στον αέρα ή ακόμα και να κάνει μια τούμπα. Ο λαός πρέπει πάντα να ακολουθεί προσεκτικά τις κινήσεις του για να στηρίζει τον βασιλιά του.
Στο τέλος, τον κατεβάζουν ξανά προσεκτικά στο έδαφος.
