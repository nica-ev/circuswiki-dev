# Σκάκι

Κατάλληλο για μικρές έως μεσαίες ομάδες

Δημιουργούνται 2 ομάδες, ίσου μεγέθους.
Ορίζεται μια ορθογώνια επιφάνεια παιχνιδιού, στις απέναντι πλευρές της οποίας παρατάσσονται οι δύο ομάδες.

Ισχύουν οι ακόλουθοι κανόνες:
* Γίνονται εναλλάξ κινήσεις.
* Μόνο 1 άτομο από την ομάδα μπορεί να κινηθεί κάθε φορά.
* Μια κίνηση σημαίνει ότι πηδάς με τα δύο πόδια και προσγειώνεσαι με ασφάλεια με τα δύο πόδια. Ένα προβολικό βήμα ή οποιοδήποτε άλλο ασταθές/ανασφαλές προσγείωση σημαίνει ότι εγκαταλείπεις την επιφάνεια παιχνιδιού.
* Η επιλογή του ποιος θα πηδήξει από την ομάδα γίνεται μόνο μέσω οπτικής επαφής. Δεν επιτρέπεται ομιλία ή χειρονομίες.
* Εάν πηδήξουν πολλοί ταυτόχρονα, ο υπεύθυνος του παιχνιδιού αποφασίζει ποιος πρέπει να εγκαταλείψει την επιφάνεια παιχνιδιού.
* Μπορείς να "χτυπήσεις" αντίπαλα πιόνια αγγίζοντάς τα με το χέρι μετά την ασφαλή προσγείωση. Αυτά πρέπει στη συνέχεια να εγκαταλείψουν την επιφάνεια παιχνιδιού.
* Κερδίζει η ομάδα που θα φτάσει πρώτη στην αντίπαλη βασική γραμμή ή που θα "χτυπήσει" όλα τα αντίπαλα πιόνια.
