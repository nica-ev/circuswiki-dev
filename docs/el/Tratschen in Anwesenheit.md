# Κουτσομπολιό παρουσία

Παιχνίδι γνωριμίας για μικρές ομάδες (ιδανικά 3-6 άτομα)

Επιλέγεται ένα άτομο για το οποίο θα γίνει "κουτσομπολιό" ή θα γίνουν εικασίες. Το άτομο αυτό κάθεται απλώς ήσυχο, ακούει τα πάντα, αλλά δεν σχολιάζει ούτε διορθώνει τίποτα.

Θέματα όπως οικογενειακή κατάσταση, καταγωγή, ενδιαφέροντα, μουσικά γούστα κ.λπ.

Μετά από λίγο, το άτομο αποκαλύπτει τα πάντα ή διορθώνει τις λανθασμένες εικασίες.

Στη συνέχεια, έρχεται η σειρά του επόμενου, μέχρι να περάσουν όλοι από την ομάδα.
