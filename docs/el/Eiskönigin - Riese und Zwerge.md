Ένα άτομο στέκεται με την πλάτη γυρισμένη προς τους άλλους, πίσω του βρίσκεται ένα μικρό αντικείμενο (π.χ. μια μπάλα).

Κάθε φορά που γυρίζει, οι υπόλοιποι πρέπει να παγώσουν. Όποιος κινείται, πρέπει να κάνει 2 βήματα πίσω (ή να πάει στην αρχή).

Στόχος είναι να κλαπεί η μπάλα και να μεταφερθεί στην γραμμή εκκίνησης.
Μόλις η μπάλα φύγει, η "Βασίλισσα του Πάγου" μπορεί να κάνει ΜΙΑ υπόδειξη κάθε φορά για το ποιος έχει την μπάλα.

Αν μαντέψει σωστά, έχει κερδίσει.
