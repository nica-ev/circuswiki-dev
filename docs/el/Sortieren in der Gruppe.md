# Ταξινόμηση στην Ομάδα

Ένα παιχνίδι συνεργασίας για μικρές έως μεσαίες ομάδες.

Υλικά: Καρέκλες ή σκαμπό ή παρόμοια για κάθε άτομο.

Οι καρέκλες τοποθετούνται σε κύκλο με μικρή απόσταση μεταξύ τους, έτσι ώστε να μπορεί κανείς να μετακινηθεί άνετα από τη μία καρέκλα στην άλλη.

Τώρα, κάθε άτομο ανεβαίνει σε μια καρέκλα. Η πρόκληση είναι η ομάδα να ταξινομηθεί χωρίς κανείς να αγγίξει το πάτωμα.

Η ταξινόμηση μπορεί να γίνει, για παράδειγμα, κατά όνομα, ύψος, ηλικία κ.λπ.

Ως δυσκολία, μπορεί να απαγορευτεί η λεκτική επικοινωνία.
Η τοποθέτηση των καρεκλών σε ευθεία γραμμή αντί για κύκλο κάνει επίσης το έργο πιο δύσκολο.
