> [!info] Σύντομη Περιγραφή
> Ένα παιχνίδι αλλαγής ομάδων, όπου αγελάδες και στάβλοι σχηματίζουν γρήγορα νέες τριάδες κατόπιν εντολής.

**Μέγεθος Ομάδας**: από 7 άτομα
**Δυσκολία**: εύκολο
**Υλικά**: κανένα
**Διάρκεια Παιχνιδιού**: 5-10 λεπτά

## **Περιγραφή Παιχνιδιού**:

Παιχνίδι για μεσαίες έως μεγάλες ομάδες.

Σχηματίζονται ομάδες των 3 ατόμων. 2 άτομα σχηματίζουν έναν στάβλο (τεντώνουν τα χέρια τους διαγώνια προς τα πάνω, ενώνουν τις παλάμες τους —> σχηματίζοντας μια στέγη) και ένα άλλο άτομο μπαίνει από κάτω. Αυτό είναι η αγελάδα.
Ένα άτομο μένει μόνο του. Αυτό το άτομο προσπαθεί τώρα να βρει μια θέση στις ομάδες των 3 ατόμων. Για να το κάνει αυτό, μπορεί να χρησιμοποιήσει 3 εντολές: Αγέλαδα, Στάβλος ή Αγέλαδα-Στάβλος.
Με την εντολή "Αγέλαδα", όλες οι αγελάδες πρέπει να τρέξουν όσο το δυνατόν γρηγορότερα από τους στάβλους τους και να βρουν έναν νέο. Κατά τη διάρκεια αυτής της στιγμής, το άτομο που έμεινε μόνο του μπορεί γρήγορα να μπει σε έναν στάβλο και να πάρει τη θέση μιας αγελάδας. Η αγελάδα που μένει έξω μπορεί τώρα να δώσει μια νέα εντολή.
Με την εντολή "Στάβλος", οι στάβλοι πρέπει να χωρίσουν και να σχηματίσουν μια στέγη πάνω από μια άλλη αγελάδα, μαζί με ένα άλλο άτομο.
Με την εντολή "Αγέλαδα-Στάβλος", όλες οι ομάδες των 3 ατόμων πρέπει να διαλυθούν και να βρουν μια νέα θέση. Εδώ, οι ρόλοι μπορούν επίσης να αλλάξουν. Οι αγελάδες μπορούν να γίνουν στάβλοι και οι στάβλοι αγελάδες.
