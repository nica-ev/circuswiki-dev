# Στάβλος

Παιχνίδι για μεσαίες έως μεγάλες ομάδες:

Δημιουργούνται ομάδες των 3 ατόμων. 2 άτομα σχηματίζουν έναν στάβλο (τεντώνουν τα χέρια τους διαγώνια προς τα πάνω, ακουμπώντας τα χέρια του άλλου —> σχηματίζοντας μια στέγη) κάτω από τη στέγη αυτή στέκεται ένα άλλο άτομο. Αυτό είναι η αγελάδα.
Ένα άτομο μένει μόνο του. Αυτό το άτομο προσπαθεί τώρα να πάρει μια θέση στις ομάδες των 3 ατόμων. Για να το κάνει αυτό, μπορεί να χρησιμοποιήσει 3 εντολές: Αγέλαδα, Στάβλος ή Αγέλαδα-Στάβλος.
Με την εντολή "Αγέλαδα", όλες οι αγελάδες πρέπει να τρέξουν όσο το δυνατόν πιο γρήγορα από τους στάβλους τους και να βρουν έναν νέο. Στο μεταξύ, το άτομο που έμεινε μόνο του μπορεί γρήγορα να μπει σε έναν στάβλο και να πάρει τη θέση μιας αγελάδας. Η αγελάδα που μένει έξω μπορεί τώρα να δώσει μια νέα εντολή.
Με την εντολή "Στάβλος", οι στάβλοι πρέπει να χωρίσουν και να σχηματίσουν μια στέγη πάνω από μια άλλη αγελάδα και με ένα άλλο άτομο.
Με την εντολή "Αγέλαδα-Στάβλος", όλες οι ομάδες των 3 ατόμων πρέπει να διαλυθούν και να βρουν μια νέα θέση. Εδώ μπορούν επίσης να αλλάξουν οι ρόλοι. Οι αγελάδες μπορούν να γίνουν στάβλοι και οι στάβλοι αγελάδες.
