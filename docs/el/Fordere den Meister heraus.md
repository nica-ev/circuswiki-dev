# Παρουσίαση παιχνιδιού "Πρόκλησε τον Δάσκαλο"

Το Beigoma έχει πολλά διασκεδαστικά παιχνίδια.

Θα παρουσιάζω σταδιακά τα παιχνίδια στα οποία έχει συμμετάσχει ο διαχειριστής.

Αυτή τη φορά, είναι το "Πρόκλησε τον Δάσκαλο".

【Κανόνας】

Αυτό είναι ένα πολύ δημοφιλές παιχνίδι.

\[Ροή παιχνιδιού\]

1. Επιλέξτε πολλούς δασκάλους Beigoma (Δάσκαλος Beigoma: Είναι επιθυμητό να είναι αυτοί που έχουν κερδίσει το τουρνουά)

2. Οι συμμετέχοντες προκαλούν τον δάσκαλο έναν προς έναν

3. Εάν ο συμμετέχων κερδίσει, συγκεντρώνει πόντους στην κάρτα πόντων

4. Συγκεντρώστε πόντους και αποκτήστε ένα Beigoma!

5. Ακόμα κι αν δεν μπορείτε να συγκεντρώσετε πόντους εκείνη την ημέρα, μπορείτε να συνεχίσετε να συγκεντρώνετε πόντους την επόμενη φορά, οπότε ακόμη και όσοι συμμετέχουν στη μέση μπορούν να το απολαύσουν.

![](https://static.wixstatic.com/media/b342b0_533ad1b9ba354ca5ac0e0df8867d63ea~mv2.jpg/v1/fill/w_734,h_489,al_c,q_90,usm_0.66_1.00_0.01/b342b0_533ad1b9ba354ca5ac0e0df8867d63ea~mv2.webp)

Οι συμμετέχοντες στα δεξιά προκαλούν τον δάσκαλο στα αριστερά στη φωτογραφία, με τη σειρά.

Είναι ένα παιχνίδι που μπορείτε να απολαύσετε συνεχώς, επειδή μπορείτε να ανταγωνιστείτε για πόντους μεταξύ γονέων, παιδιών και φίλων.

【Πόντος】

Υπάρχουν διάφοροι τρόποι διανομής πόντων, αλλά στο Ota Bunkanomori, που διεξάγεται από τον διαχειριστή, ακολουθούμε την εξής διαδικασία:

- Παίζοντας και κερδίζοντας: 2 πόντοι

- Περιστρέφοντας για πολλή ώρα και κερδίζοντας (ο Riki κερδίζει): 1 πόντος

- Ισοπαλία, ήττα: 0 πόντοι

- Εάν συγκεντρώσετε 20 πόντους, θα λάβετε ένα κανονικό δώρο Beigoma.
