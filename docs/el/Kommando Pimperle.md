# Εντολή Πιμπερλε

Παιχνίδι για οποιοδήποτε μέγεθος ομάδας:

Όλα τα άτομα κάθονται σε κύκλο.
Τα χέρια απλώνονται προς το κέντρο και τα δάχτυλα χτυπούν ρυθμικά στο πάτωμα.
Ο συντονιστής του παιχνιδιού μπορεί τώρα να δώσει διάφορες εντολές:
- επίπεδο (τα δάχτυλα ακουμπούν στο πάτωμα)
- πλάτη (τα χέρια ακουμπούν με την παλάμη προς τα πάνω στο πάτωμα)
- γέφυρα (τα χέρια σχηματίζουν μια γέφυρα στο πάτωμα)
- γροθιά (οι γροθιές ακουμπούν στο πάτωμα)
- ράβδος (τα δάχτυλα δείχνουν στον αέρα)
Τώρα, αυτές οι εντολές επιτρέπεται να εκτελεστούν μόνο εάν ο συντονιστής του παιχνιδιού πει τη λέξη "Εντολή" πριν από κάθε ανακοίνωση (π.χ. "Εντολή γροθιά").
Εάν δεν την πει, αλλά μόνο την ίδια την εντολή (π.χ. "Γροθιά"), πρέπει να συνεχιστεί το χτύπημα των δαχτύλων στο πάτωμα. Ωστόσο, ο συντονιστής του παιχνιδιού μπορεί πάντα να εκτελέσει την εντολή για να μπερδέψει τους συμπαίκτες.
Όποιος κάνει λάθος, πρέπει να τρέξει έναν γύρο γύρω από τον κύκλο.

Παραλλαγή: Το παιχνίδι μπορεί να παιχτεί και όρθιοι.
Για αυτό, αντί για το χτύπημα των δαχτύλων, τρέχουμε επιτόπου. Οι εντολές εκτελούνται τώρα με το σώμα.
- επίπεδο (ξαπλώνουμε μπρούμυτα)
- πλάτη (ξαπλώνουμε ανάσκελα)
- γέφυρα (τοποθετούμε χέρια και πόδια στο πάτωμα, σηκώνουμε τους γλουτούς στον αέρα)
- γροθιά (γονατίζουμε στο πάτωμα και γινόμαστε πολύ μικροί)
- ράβδος (τεντώνουμε τα χέρια προς τα πάνω, πόδια ενωμένα)
Μετά από κάθε εκτέλεση των εντολών, συνεχίζουμε να τρέχουμε επιτόπου.

Οι εντολές μπορούν επίσης να προσαρμοστούν στην ηλικιακή ομάδα.
Για μικρά παιδιά, για παράδειγμα, μπορούν να χρησιμοποιηθούν κινήσεις ζώων (βάτραχος, φίδι, ελέφαντας...).
