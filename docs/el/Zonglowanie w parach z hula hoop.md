# Ζογκλερικά με Hula Hoop σε Ζευγάρια

Μια άσκηση για ζευγάρια που αναπτύσσει τη συνεργασία, τον ρυθμό, το συγχρονισμό και τη δουλειά με τον κρίκο.

## Στάδιο Ι

Δύο hula hoop ανά ζευγάρι.

Εξασκούμαστε συγχρονισμένα:

1. Κύλιση.
2. Ρίψη.

## Στάδιο ΙΙ

Τέσσερα hula hoop ανά ζευγάρι.

Εξασκούμαστε συγχρονισμένα:

1. Κύλιση.
2. Ρίψη.
3. Κύλιση και ρίψη.
4. Επαναλαμβάνουμε όλα τα στάδια ασύγχρονα.
