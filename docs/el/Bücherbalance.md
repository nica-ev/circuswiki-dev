# Ισορροπία με Βιβλία

Παιχνίδι για μικρές έως μεσαίες ομάδες:

Κάθε άτομο παίρνει ένα βιβλίο.
Στη συνέχεια, πρέπει να προσπαθήσει να ισορροπήσει το βιβλίο στην παλάμη του, δοκιμάζοντας ταυτόχρονα πόσο μπορεί να κινήσει το σώμα του (να καθίσει στο πάτωμα, να γυρίσει στο πλάι, να ξαπλώσει μπρούμυτα, να κυλήσει στο πλάι κ.λπ.).
Όταν αυτό επιτευχθεί, η δυσκολία μπορεί να αυξηθεί τοποθετώντας το βιβλίο στην επιφάνεια ενός ποδιού.
Και πάλι, δοκιμάζονται ποιες κινήσεις είναι δυνατές χωρίς να πέσει το βιβλίο από το πόδι.
