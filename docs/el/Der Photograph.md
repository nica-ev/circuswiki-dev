# Ο Φωτογράφος

Θεατρικό / Τσιρκοπαιδαγωγικό παιχνίδι για μικρές έως μεσαίες ομάδες.

Η ομάδα κινείται ελεύθερα στον χώρο του παιχνιδιού. Με ένα σήμα, η αποστολή είναι να αναπαραστήσει ένα θέμα γύρω από το κέντρο της σκηνής (η κίνηση παγώνει).
Η ολοκληρωμένη εικόνα φωτογραφίζεται.

Μετά από μερικούς γύρους, η ομάδα κάθεται μαζί και αξιολογεί τις φωτογραφίες: σύνθεση της εικόνας, κατανομή στον χώρο, ορατότητα των ατόμων κ.λπ.

Πιθανά θέματα: Παραμύθια, Τσίρκο, Καθάρισμα, Καθημερινότητα γραφείου, Ψώνια, Παιδική χαρά, Στην παραλία, κ.ά.
