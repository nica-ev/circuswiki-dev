# Δημιουργία Μηχανών

Η δραστηριότητα μπορεί να θεωρηθεί ως μια επέκταση της άσκησης [Εικόνες](Obrazki.md): αντί για μια στατική εικόνα, η ομάδα δημιουργεί μια επαναλαμβανόμενη κίνηση.

## Μηχανή για...

Οι ομάδες έχουν 10 λεπτά για να δημιουργήσουν μια μηχανή που θα έχει έναν συγκεκριμένο σκοπό, π.χ.:

- καρφώνει καρφιά
- καθαρίζει τον κόσμο
- συνδέει
- αναπηδά
- γράφει γράμματα

Χρησιμοποιούμε αντικείμενα.

## Τσίρκο-Μηχανή

Οι ομάδες έχουν 10 λεπτά για να δημιουργήσουν μια μηχανή και να χρησιμοποιήσουν συγκεκριμένους κανόνες, π.χ.:

- πρέπει να χρησιμοποιηθούν τουλάχιστον 5 μπάλες, 2 στεφάνια και 1 μαντήλι
- πρέπει να υπάρχει κίνηση τουλάχιστον ενός αντικειμένου από κάτω προς τα πάνω
- πιο δύσκολη παραλλαγή: σπειροειδής κίνηση
- σε έναν κύκλο λειτουργίας της μηχανής πρέπει να γίνουν 3 ρίψεις και 1 κύλιση
- κάθε λειτουργία της μηχανής πρέπει κατά τη διάρκειά της να περιλαμβάνει 2 καθίσματα

Οι δυνατότητες ως προς τους κανόνες περιορίζονται μόνο από τη φαντασία της ομάδας και του συντονιστή.
