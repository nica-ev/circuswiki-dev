# Αρχές για τη Διδασκαλία Παιχνιδιών Κίνησης

**1. Ιδέα και Εξέλιξη του Παιχνιδιού:**

- **Ιδέα του παιχνιδιού:** Να μεταδοθεί η ιδέα του παιχνιδιού με σαφήνεια, αλλά και συνοπτικά, αφήνοντας χώρο για προσωπική εξερεύνηση.
- **Εξέλιξη του παιχνιδιού:** Να μην καθορίζεται πλήρως το παιχνίδι. Οι κανόνες να εισάγονται σταδιακά. Μόνο ένα παιχνίδι που έχει αναπτυχθεί από τους ίδιους τους παίκτες δημιουργεί χαρά.
- **Κατανόηση του παιχνιδιού:** Να επιδιώκεται η γρήγορη κατανόηση της ιδέας του παιχνιδιού. Ο αριθμός των κανόνων να περιορίζεται στο απολύτως απαραίτητο.

**2. Πλαίσιο και Οργάνωση:**

- **Χώρος παιχνιδιού:** Ακριβή όρια του χώρου παιχνιδιού ενισχύουν το κίνητρο και αποτρέπουν τις διαφωνίες.
- **Σχηματισμός ομάδων:** Οι ομάδες να μην σχηματίζονται με επιλογή.
- **Διάρκεια παιχνιδιού:** Να επιτρέπεται στους παίκτες να απολαύσουν το παιχνίδι, αλλά να μην παραμένουν για πολύ σε ένα μόνο παιχνίδι.

**3. Συμμετοχή και Συμπερίληψη:**

- **Συμμετοχή:** Να αποφεύγεται ο αποκλεισμός. Όλοι οι μαθητές να μπορούν να συμμετέχουν ενεργά στο παιχνίδι.

**4. Ρόλος του Εκπαιδευτικού και Αλληλεπίδραση:**

- **Ρόλος του εκπαιδευτικού:** Ο εκπαιδευτικός μπορεί να ζωντανέψει το παιχνίδι με τη συμμετοχή του, αλλά δεν πρέπει να ενεργεί ως κριτής.
- **Πνευματική ενεργοποίηση:** Να προωθείται η πνευματική ενεργοποίηση των παικτών, να ενθαρρύνεται η ζωηρή συμμετοχή και η δημιουργική συνδιαμόρφωση.
- **Προσαρμοστικότητα:** Να γίνονται προσαρμογές στις συνθήκες του παιχνιδιού και, αν χρειαστεί, αλλαγές στους κανόνες. Να αξιοποιούνται οι δυνατότητες για παραλλαγές.
- **Ένταση:** Να επιδιώκεται υψηλός βαθμός έντασης. Να ενδυναμώνονται οι παίκτες για αυτόνομη δράση.

**5. Μετάδοση Αξιών και Κοινωνική Μάθηση:**

- **Τάξη και ειλικρίνεια:** Να απαιτούνται τάξη και ειλικρίνεια ακόμη και στα παιχνίδια κίνησης.
- **Κοινωνική μάθηση:** Τα παιχνίδια να χρησιμοποιούνται για την προώθηση της κοινωνικής μάθησης, της συνεργατικής συμπεριφοράς και της επικοινωνίας. Να παρεμβαίνεται παιδαγωγικά όταν χάνεται η δικαιοσύνη, η συντροφικότητα και το αίσθημα κοινότητας, και όταν η απόδοση στο παιχνίδι/η επιδίωξη της επιτυχίας υπερισχύουν.
- **Εμπειρία παιχνιδιού:** Να μεταδίδεται η θετική εμπειρία του παιχνιδιού, η χαρά και η διασκέδαση.

**6. Βασικά Χαρακτηριστικά:**

- **Χαρακτηριστικά παιχνιδιού:** Η ευθυμία, η αγωνία και η χαρά είναι ουσιώδη χαρακτηριστικά των παιχνιδιών κίνησης.
