# Κανείς δεν θέλει να είναι μόνος

**Μέγεθος ομάδας**: από 8 παίκτες και πάνω
**Δυσκολία**: απλό
**Υλικά**: κανένα
**Διάρκεια παιχνιδιού**: όσο διασκεδάζει

**Περιγραφή παιχνιδιού**:
Όλοι οι παίκτες στέκονται σε ζευγάρια σε έναν κύκλο, εκτός από έναν που στέκεται μόνος. Ο παίκτης που στέκεται μόνος μπορεί τώρα να πει ένα όνομα. Αυτός που καλείται προσπαθεί να τρέξει πολύ γρήγορα προς τον μοναχικό παίκτη. Όμως, κανείς δεν θέλει να είναι μόνος: Γι' αυτό, ο παρτενέρ του παίκτη που καλείται, προσπαθεί να τον κρατήσει από τους ώμους ή να τον αγκαλιάσει γρήγορα, πριν προλάβει να φύγει τρέχοντας. Δεν επιτρέπεται να τον κυνηγήσει! Αν είναι ήδη αργά, μπορεί να πει ένα άλλο όνομα και έτσι να αποκτήσει έναν νέο παρτενέρ δίπλα του.

**Παραλλαγή για προχωρημένους**:
Όσοι βρίσκουν αυτό πολύ εύκολο, μπορούν να παίξουν το παιχνίδι έτσι ώστε ο καθένας να υιοθετεί το όνομα του τρέχοντος παρτενέρ του. Δηλαδή, τα ζευγάρια αλλάζουν ονόματα. Αν κατά τη διάρκεια του παιχνιδιού αλλάξει ο γείτονας, τότε αλλάζουν ξανά και τα ονόματα.
