# Παιχνίδι Εργασιών

Παιχνίδι για κάθε μέγεθος ομάδας:

Όλα τα άτομα κινούνται ελεύθερα στον χώρο.

Ο/Η υπεύθυνος/η του παιχνιδιού ανακοινώνει δυνατά μια εργασία, π.χ. «4 άτομα, 3 κεφάλια, 6 πόδια».

Τώρα οι παίκτες πρέπει να βρουν γρήγορα ομάδες των 4 ατόμων. Πρέπει να ακουμπήσουν τα κεφάλια τους στο πάτωμα και να ακουμπήσουν επίσης το πάτωμα με τα πόδια τους. Ωστόσο, δύο άτομα επιτρέπεται να στέκονται μόνο στο ένα πόδι, ώστε να εκπληρωθεί η εργασία «6 πόδια».

Η επόμενη εργασία είναι: «2 άτομα, 2 πόδια, 4 χέρια, 2 μύτες».

Τώρα πρέπει να σχηματιστούν ζευγάρια των 2 ατόμων. Και τα δύο άτομα πρέπει να στέκονται στο ένα πόδι, ακουμπώντας τα χέρια και τη μύτη στο πάτωμα.

…

Οι εργασίες μπορούν να ξεκινούν απλά και να αυξάνονται από γύρο σε γύρο.

Το παιχνίδι μπορεί να τελειώσει όταν μια εργασία δεν μπορεί πλέον να εκπληρωθεί από όλους.
