# Αν ήμουν βασιλιάς...

Δραματική έκφραση, Θέατρο / Τσίρκο-παιδαγωγική

Ένα άτομο από την ομάδα στέκεται σε ένα βάθρο και φωνάζει «Αν ήμουν βασιλιάς, τότε θα...» και στη συνέχεια αναφέρει μια δραστηριότητα που θα έκανε, π.χ. «...έτρωγα παγωτό όλη μέρα» ή «...πηδούσα στο ένα πόδι», «...μεταμορφωνόμουν σε μονόκερο».

Η ομάδα αναπαριστά στη συνέχεια αυτή τη δραστηριότητα, μέχρι να ανέβει ένα άλλο άτομο από την ομάδα στο βάθρο και να φωνάξει ξανά «Αν ήμουν βασιλιάς...».
