# Ανθρώπινη Μνήμη

Παιχνίδι για μεσαίες έως μεγάλες ομάδες:

Δύο άτομα βγαίνουν από την αίθουσα.
Οι υπόλοιποι σχηματίζουν ζευγάρια και σκέφτονται μαζί μια κίνηση και έναν ήχο.
Οι δύο παίκτες που βρίσκονται έξω επιστρέφουν στην αίθουσα και ξεσκεπάζουν εναλλάξ τις ζωντανές κάρτες μνήμης, ονομάζοντας τα ονόματα δύο ατόμων κάθε φορά. Αυτά σηκώνονται και παρουσιάζουν την κίνησή τους και τον ήχο τους.
Αν πρόκειται για ίδιο ζευγάρι, αυτό αποχωρεί από τον χώρο του παιχνιδιού και μπορεί να ξεσκεπαστεί ένα δεύτερο ζευγάρι.
Νικητής είναι ο παίκτης με τα περισσότερα ζευγάρια.
