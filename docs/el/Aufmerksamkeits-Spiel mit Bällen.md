# Παιχνίδι Συγκέντρωσης με Μπάλες

Παιχνίδι για μικρές και μεσαίες ομάδες.
Όλοι τρέχουν ελεύθερα σε μια καθορισμένη περιοχή παιχνιδιού.
(βλ. επίσης ελεύθερο τρέξιμο / θεατρικές ασκήσεις / γέμισμα χώρου)
Ένα άτομο έχει μια μπάλα. Αυτό το άτομο, ενώ τρέχει, έρχεται σε οπτική επαφή με ένα άλλο άτομο και του πετάει την μπάλα.

Σημαντικό: το άτομο που δέχεται την μπάλα θα πρέπει να βρίσκεται σχετικά κοντά, και να πεταχτεί η μπάλα μόνο αφού έχει εδραιωθεί οπτική επαφή.

Ο βαθμός δυσκολίας μπορεί να αυξηθεί κατά βούληση με την αύξηση του αριθμού των μπαλών.
