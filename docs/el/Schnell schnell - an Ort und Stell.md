# Γρήγορα, γρήγορα - στη θέση σας

Ένα παιχνίδι αντίδρασης για μεσαίου μεγέθους ομάδες.

Ο/Η συντονιστής/τρια στέκεται στη μέση ενός τετραγώνου. Οι παίκτες/τριες στέκονται μοιρασμένοι σε ίσες ομάδες στις πλευρές του τετραγώνου.

Ο/Η συντονιστής/τρια στρέφεται (90, 180, 270, 360 μοίρες) - τώρα όλοι πρέπει να ευθυγραμμιστούν ξανά / να αλλάξουν θέσεις έτσι ώστε να αποκατασταθεί η αρχική κατάσταση.
Όταν μια ομάδα είναι ξανά πλήρης, φωνάζει "Γρήγορα, γρήγορα - στη θέση σας!"
