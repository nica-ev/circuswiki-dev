# Συμμετοχή στην τεκμηρίωση – Έτσι γίνεται εύκολα!

Γεια σε όλους! Χαιρόμαστε που θέλετε να βοηθήσετε στην τεκμηρίωσή μας. 😊 Εδώ είναι μια απλή οδηγία για το πώς μπορείτε να το κάνετε:

## Τι χρειάζεσαι

1.  **Λογαριασμός GitHub:**
    *   Δημιουργήστε έναν δωρεάν λογαριασμό GitHub, αν δεν έχετε ήδη: [https://github.com/join](https://github.com/join)
    *   Το χρειαζόμαστε για να λειτουργήσουν όλα.

2.  **GitHub Desktop:**
    *   Κατεβάστε και εγκαταστήστε το GitHub Desktop: [https://desktop.github.com/](https://desktop.github.com/)
    *   Το πρόγραμμα κάνει την εργασία με το Git ευκολότερη, ακόμα κι αν δεν είστε εξοικειωμένοι με αυτό.

## Ξεκινάμε!

1.  **Αντιγραφή του αποθετηρίου:**
    *   Πηγαίνετε στην ενότητα τεκμηρίωσης στο GitHub (π.χ. `nica-ev/docs`) και κάντε κλικ στο κουμπί "Fork".
    *   Αυτό δημιουργεί ένα δικό σας αντίγραφο της ενότητας, όπου μπορείτε να εργαστείτε χωρίς να χαλάσετε τίποτα. 😉

2.  **Λήψη του αποθετηρίου στον υπολογιστή σας:**
    *   Ανοίξτε το GitHub Desktop.
    *   Κάντε κλικ στο "File" -> "Clone repository...".
    *   Επιλέξτε το αντίγραφό σας από τη λίστα στο GitHub.
    *   Επιλέξτε έναν φάκελο στον υπολογιστή σας όπου θέλετε να αποθηκεύσετε την ενότητα.
    *   Κάντε κλικ στο "Clone".
    *   Τώρα έχετε ένα αντίγραφο της ενότητας στον υπολογιστή σας.

3.  **(Προαιρετικό) Δημιουργία νέου χώρου εργασίας:**
    *   Στο GitHub Desktop, κάντε κλικ στο κουμπί "Current Branch" (συνήθως πάνω αριστερά).
    *   Εισαγάγετε ένα νέο όνομα για τον χώρο εργασίας σας (π.χ. `neue-seite`, `fehler-korrigieren`).
    *   Κάντε κλικ στο "Create branch".
    *   Οι χώροι εργασίας βοηθούν στον διαχωρισμό των αλλαγών σας. Αν κάτι πάει στραβά, μπορείτε απλά να διαγράψετε τον χώρο εργασίας.
    *   **Σημείωση:** Η δημιουργία νέου χώρου εργασίας είναι προαιρετική, αλλά είναι καλή ιδέα για να οργανώσετε τις αλλαγές σας.

4.  **Πραγματοποίηση αλλαγών:**
    *   Χρησιμοποιήστε το πρόγραμμα επεξεργασίας κειμένου σας (π.χ. Notepad, VS Code) για να επεξεργαστείτε τα αρχεία στην ενότητα στον υπολογιστή σας.
    *   Εδώ μπορείτε να προσθέσετε κείμενα, να διορθώσετε λάθη κ.λπ.
    *   **Σημαντικό:** Χρησιμοποιήστε Markdown για τη μορφοποίηση (δείτε παρακάτω).

5.  **Αποθήκευση αλλαγών:**
    *   Στο GitHub Desktop, στην καρτέλα "Changes", θα δείτε τα τροποποιημένα αρχεία σας.
    *   Γράψτε μια σύντομη περίληψη στο πεδίο "Summary".
    *   Κάντε κλικ στο "Commit to `<branch-name>`" (ή "Commit to main", αν δεν χρησιμοποιήσατε χώρο εργασίας).
    *   Η αποθήκευση είναι σαν ένα ενδιάμεσο σημείο της εργασίας σας.

6.  **Μεταφόρτωση αλλαγών:**
    *   Στο GitHub Desktop, κάντε κλικ στο "Push origin".
    *   Αυτό θα ανεβάσει τις αλλαγές σας στο αντίγραφό σας στο GitHub.

7.  **Υποβολή αλλαγών για έλεγχο:**
    *   Στο GitHub Desktop, κάντε κλικ στο "Create Pull Request". Στη συνέχεια, θα ανοίξει μια σελίδα στο GitHub.
    *   Ελέγξτε τις αλλαγές σας εκεί και κάντε κλικ στο "Create Pull Request".
    *   Ένα Pull Request είναι σαν ένα αίτημα για να ενσωματωθούν οι αλλαγές σας στην κύρια ενότητα.

## Σημαντικά πράγματα που πρέπει να γνωρίζετε

*   **Markdown:** Είναι σαν μια απλή γλώσσα για κείμενα. Εδώ μια σύντομη επισκόπηση:
    *   `# Επικεφαλίδα 1`
    *   `## Επικεφαλίδα 2`
    *   `**Έντονα**`
    *   `*Πλάγια*`
    *   `- Λίστα`
    *   `[Σύνδεσμος](https://www.example.com)`
*   **Μηνύματα κατά την αποθήκευση:** Γράψτε σύντομα μηνύματα για τις αποθηκεύσεις σας, ώστε όλοι να γνωρίζουν τι κάνατε.
*   **Υπομονή:** Στην αρχή μπορεί να χρειαστεί λίγη εξάσκηση. Απλά ρωτήστε αν κάτι δεν είναι σαφές!

Ευχαριστούμε για τη βοήθειά σας! 🙌
