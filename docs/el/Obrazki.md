# Εικόνες

Δραστηριότητα για ομάδες περίπου 4-8 ατόμων.

## Στάδιο Ι

Οι ομάδες έχουν εναλλάξ 7 δευτερόλεπτα για να δημιουργήσουν μια «εικόνα» με τα σώματά τους.

Η λέξη-κλειδί μπορεί να είναι γνωστή σε όλους ή μυστική για τις υπόλοιπες ομάδες. Στη δεύτερη περίπτωση, παίζουμε ομαδικά παντομίμα.

Ενδεικτικές λέξεις-κλειδιά:

- γλάστρα
- λουλούδι
- ομπρέλα
- αυτοκίνητο
- τραπέζι
- χτένα
- μίξερ
- κούπα
- πιάτο

## Στάδιο ΙΙ

Προσθέτουμε 3-7 δευτερόλεπτα στην αντίστροφη μέτρηση. Ο στόχος και οι κανόνες είναι οι ίδιοι, αλλά η ομάδα μπορεί να χρησιμοποιήσει κυκλικά αντικείμενα.
