# Αρκούδα του Γέλιου

**Μέγεθος Ομάδας**: Από 6 παίκτες και πάνω
**Δυσκολία**: Απλό
**Υλικά**: Κανένα
**Διάρκεια Παιχνιδιού**: περίπου 4 λεπτά

**Περιγραφή Παιχνιδιού**:
Πριν την έναρξη του παιχνιδιού, πρέπει να επιλεγεί ένα άτομο που θα είναι η «Αρκούδα του Γέλιου». Όλοι οι υπόλοιποι παίκτες ξαπλώνουν ανάσκελα στο πάτωμα. Όλοι τους έχουν τα μάτια ανοιχτά και κοιτούν προς την οροφή. Από εδώ και πέρα, όσοι είναι ξαπλωμένοι δεν επιτρέπεται να μιλήσουν ή να κάνουν θόρυβο. Η «Αρκούδα του Γέλιου» πρέπει τώρα να προσπαθήσει να κάνει τους ξαπλωμένους παίκτες να γελάσουν, αλλά χωρίς να τους αγγίξει! Αν η «Αρκούδα του Γέλιου» καταφέρει να κάνει κάποιον να γελάσει, αυτός γίνεται επίσης «Αρκούδα του Γέλιου» και μπορούν να συνεχίσουν οι δύο τους, μέχρι να μην υπάρχουν πια ξαπλωμένοι παίκτες. Το μόνο σημαντικό είναι ότι οι ξαπλωμένοι παίκτες δεν επιτρέπεται να σφίγγουν τα πρόσωπά τους. Όποιος πρέπει να γελάσει, ας γελάσει!
