> [!info] Σύντομη Περιγραφή
> Ένα ήρεμο παιχνίδι, στο οποίο η αρκούδα του γέλιου πρέπει να κάνει τους ξαπλωμένους παίκτες να γελάσουν χωρίς να τους αγγίξει.

**Μέγεθος Ομάδας**: Από 6 παίκτες και άνω
**Δυσκολία**: Απλή
**Υλικά**: Κανένα
**Διάρκεια Παιχνιδιού**: περ. 4 λεπτά

## **Περιγραφή Παιχνιδιού**:

Πριν την έναρξη του παιχνιδιού, πρέπει να επιλεγεί ένα άτομο που θα είναι η αρκούδα του γέλιου. Όλοι οι υπόλοιποι παίκτες ξαπλώνουν ανάσκελα στο πάτωμα. Όλοι έχουν τα μάτια τους ανοιχτά και κοιτούν προς την οροφή. Από αυτό το σημείο και μετά, όσοι είναι ξαπλωμένοι δεν επιτρέπεται να μιλήσουν ή να κάνουν θορύβους. Η αρκούδα του γέλιου πρέπει τώρα να προσπαθήσει να κάνει τους ξαπλωμένους παίκτες να γελάσουν, αλλά χωρίς να τους αγγίξει! Αν η αρκούδα του γέλιου καταφέρει να κάνει κάποιον να γελάσει, αυτός γίνεται επίσης αρκούδα του γέλιου και μπορούν να συνεχίσουν οι δύο τους, μέχρι να μην υπάρχουν πια ξαπλωμένοι παίκτες. Το μόνο που είναι σημαντικό είναι ότι οι ξαπλωμένοι παίκτες δεν πρέπει να σφίγγουν τα πρόσωπά τους. Όποιος πρέπει να γελάσει, πρέπει να γελάσει!
