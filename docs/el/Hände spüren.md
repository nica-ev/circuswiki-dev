# Αίσθηση των χεριών

Παιχνίδι χαλάρωσης για οποιοδήποτε μέγεθος ομάδας:

Δημιουργούνται ομάδες των 4-5 ατόμων.

Ένα άτομο ξαπλώνει μπρούμυτα και κλείνει τα μάτια.

Οι υπόλοιποι συνεννοούνται μη λεκτικά πόσα χέρια θέλουν να τοποθετήσουν ταυτόχρονα πάνω στο σώμα του ξαπλωμένου.

Ο/η ξαπλωμένος/η στο πάτωμα πρέπει τώρα να μαντέψει πόσα χέρια βρίσκονται πάνω στο σώμα του/της.

Ανάλογα με τον χρόνο και την αίσθηση των συμμετεχόντων, μπορούν να παιχτούν αρκετοί γύροι. Στη συνέχεια, γίνεται αλλαγή.

**Δείτε επίσης:**
[Ρομπότ](Roboter.md) - και εδώ η δράση είναι μη λεκτική και αφορά την αίσθηση.
