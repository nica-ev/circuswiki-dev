# NICA e.V. - Δίκτυο για τις συμπεριληπτικές τέχνες του τσίρκου

Το NICA e.V. αντιλαμβάνεται τον εαυτό του ως ένα δίκτυο που διαδίδει και αναπτύσσει συμπεριληπτικές μεθόδους εκπαίδευσης στο τσίρκο.

Η εργασία μας βασίζεται σε έργα, έρευνα, ανάπτυξη και μεταφορά γνώσης.

Ενισχύουμε περιφερειακά, κρατικά, ευρωπαϊκά και διεθνή δίκτυα για τη συμπεριληπτική εκπαίδευση στο τσίρκο και υλοποιούμε έργα με διαφορετικές ομάδες-στόχους.

Σε συνεργασία με πανεπιστήμια, αξιολογούμε συμπεριληπτικές μεθόδους εκπαίδευσης στο τσίρκο. Συνδυάζουμε διαφορετικές μεθόδους και τις αναπτύσσουμε περαιτέρω. Μέσω επιμορφώσεων, εργαστηρίων και ενσωμάτωσης των μεθόδων στο μαθησιακό περιβάλλον, προωθούμε τη μεταφορά γνώσης.

Δραστηριοποιούμαστε τόσο σε περιφερειακό όσο και σε διεθνές επίπεδο.
