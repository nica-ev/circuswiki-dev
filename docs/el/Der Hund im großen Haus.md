> [!info] Σύντομη Περιγραφή
> Ένα δυναμικό παιχνίδι προθέρμανσης για οποιοδήποτε μέγεθος ομάδας, που συνδυάζει κίνηση, συντονισμό και διασκέδαση.

**Μέγεθος Ομάδας**: Οποιοδήποτε
**Δυσκολία**: Εύκολο
**Υλικά**: Κανένα
**Διάρκεια Παιχνιδιού**: Περίπου 5-10 λεπτά

## **Περιγραφή Παιχνιδιού**:

Όλα τα άτομα στέκονται σε κύκλο και μιμούνται τις κινήσεις του/της οδηγού του παιχνιδιού.

| Κείμενο                               | Κίνηση                                                                    |
| :------------------------------------ | :------------------------------------------------------------------------ |
| Σε ένα σπίτι, σπίτι μεγάλο             | Τεντώνεσαι όσο πιο ψηλά μπορείς (ανοίγεις τα χέρια πλατιά)                 |
| Ζει ένα ποντικάκι μικρό                 | Σκύβεις χαμηλά στο πάτωμα (γίνεσαι μικρός)                                 |
| Και σε αυτό το σπίτι, σπίτι μεγάλο     | Τεντώνεσαι όσο πιο ψηλά μπορείς (ανοίγεις τα χέρια πλατιά)                 |
| Ζει κι ένας σκύλος                     | Βάζεις χέρια και πόδια στο πάτωμα, σηκώνεις τον πισινό (θέση σκύλου)       |
| Πολύ υγιής                             | Σηκώνεις το αριστερό πόδι ψηλά (διατηρώντας τη θέση σκύλου)              |
| Πραγματικά πολύ υγιής                  | Σηκώνεις το δεξί πόδι ψηλά (διατηρώντας τη θέση σκύλου)                 |
| Και σε αυτό το σπίτι, σπίτι μεγάλο     | Τεντώνεσαι όσο πιο ψηλά μπορείς (ανοίγεις τα χέρια πλατιά)                 |
| Ζει κι ένα φιδάκι                      | Ξαπλώνεις μπρούμυτα (κινείσαι σαν φίδι)                                   |
| Τότε ο σκύλος φοβάται πολύ            | Βάζεις χέρια και πόδια στο πάτωμα, σηκώνεις τον πισινό (φοβισμένη θέση σκύλου) |
| Και ξεφεύγει – σε ένα νέο σπίτι      | Αλλάζεις θέση (βρίσκεις γρήγορα μια νέα θέση στον κύκλο)                |

Στο τέλος της ιστορίας, αλλάζεις θέση έτσι ώστε όλοι να βρίσκονται ξανά σε κύκλο, αλλά σε διαφορετικό σημείο.
Η ιστορία επαναλαμβάνεται και λέγεται όλο και πιο γρήγορα κάθε φορά.
