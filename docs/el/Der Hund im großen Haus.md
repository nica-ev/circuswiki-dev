> [!info] Σύντομη περιγραφή
> Ένα αφηγηματικό παιχνίδι προθέρμανσης, όπου η ομάδα αναπαριστά μια σύντομη ιστορία με αντίστοιχες κινήσεις.

**Μέγεθος ομάδας**: 5-30 άτομα
**Δυσκολία**: Εύκολο
**Υλικά**: Κανένα
**Διάρκεια παιχνιδιού**: Περίπου 5-10 λεπτά

## **Περιγραφή παιχνιδιού**:

Όλοι στέκονται σε κύκλο και μιμούνται τις κινήσεις του/της συντονιστή/τριας.

| Κείμενο                               | Κίνηση                                                                    |
| :------------------------------------ | :------------------------------------------------------------------------ |
| Σε ένα μεγάλο, μεγάλο σπίτι           | Τεντώνεσαι όσο πιο ψηλά μπορείς (ανοίγεις τα χέρια διάπλατα)               |
| Ζει ένα μικροσκοπικό ποντικάκι         | Σκύβεις χαμηλά στο πάτωμα (γίνεσαι μικρός/ή)                               |
| Και σε αυτό το μεγάλο, μεγάλο σπίτι     | Τεντώνεσαι όσο πιο ψηλά μπορείς (ανοίγεις τα χέρια διάπλατα)               |
| Ζει κι ένας σκύλος                     | Βάζεις χέρια και πόδια στο πάτωμα, σηκώνεις τον ποπό στον αέρα (στάση σκύλου) |
| Πολύ υγιής                            | Σηκώνεις το αριστερό πόδι ψηλά (διατηρώντας τη στάση σκύλου)              |
| Πραγματικά πολύ υγιής                  | Σηκώνεις το δεξί πόδι ψηλά (διατηρώντας τη στάση σκύλου)                 |
| Και σε αυτό το μεγάλο, μεγάλο σπίτι     | Τεντώνεσαι όσο πιο ψηλά μπορείς (ανοίγεις τα χέρια διάπλατα)               |
| Ζει κι ένα φίδι                       | Ξαπλώνεις μπρούμυτα (κινείσαι σαν φίδι)                                    |
| Ο σκύλος τρομάζει πολύ                | Βάζεις χέρια και πόδια στο πάτωμα, σηκώνεις τον ποπό στον αέρα (τρομαγμένη στάση σκύλου) |
| Και το σκάει - σε ένα νέο σπίτι       | Αλλάζεις θέση (βρίσκεις γρήγορα μια νέα θέση στον κύκλο)                  |

Στο τέλος της ιστορίας, αλλάζετε θέση έτσι ώστε όλοι να βρίσκεστε ξανά σε κύκλο, αλλά σε διαφορετικό σημείο.
Η ιστορία επαναλαμβάνεται και λέγεται όλο και πιο γρήγορα.
