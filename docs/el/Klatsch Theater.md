# Θέατρο "Κλατς"

**Μέγεθος ομάδας**: 4 έως 20 παίκτες
**Δυσκολία**: αρκετά εύκολο
**Υλικά**: κανένα
**Διάρκεια παιχνιδιού**: περίπου 7 λεπτά

**Περιγραφή παιχνιδιού**:
Αυτό το παιχνίδι μπορεί να παιχτεί σε δύο παραλλαγές.

**Παραλλαγή 1**:
Δύο, τρεις ή τέσσερις παίκτες σχηματίζουν μια παγωμένη εικόνα μπροστά από τους υπόλοιπους παίκτες. Όλοι οι υπόλοιποι παίκτες την παρατηρούν. Όποιος έχει μια ιδέα για το πώς θα μπορούσε να αντικαταστήσει έναν παίκτη της υπάρχουσας εικόνας με μια διαφορετική στάση, χτυπάει δυνατά τις παλάμες του μία φορά. Στη συνέχεια, μπορεί να προχωρήσει μπροστά και να αγγίξει αυτόν που θέλει να αντικαταστήσει. Αυτός φεύγει από τη θέση του και ενώνεται με το κοινό, τους άλλους παίκτες. Ο παίκτης που χτύπησε τις παλάμες του παίρνει τώρα την προμελετημένη στάση και ο επόμενος μπορεί να χτυπήσει τις παλάμες του. Για να επεκταθεί το όλο θέμα, μπορεί να δημιουργηθεί μια εικόνα όπου κάθε άτομο της εικόνας εκτελεί μια μικρή κίνηση. Αυτό μπορεί να οδηγήσει σε πολύ αστείες νέες εικόνες. Ένα βήμα παραπέρα θα ήταν να γίνει ένας ήχος για κάθε κίνηση.

**Παραλλαγή 2**:
Ίδια αρχή με την πρώτη παραλλαγή, μόνο που ένας παίκτης ξεκινά, μετά ένας άλλος χτυπάει τις παλάμες του, ενώνεται και αυτό συνεχίζεται μέχρι να ενσωματωθούν όλοι στην εικόνα. Αυτό είναι το σημαντικό σε αυτήν την εκδοχή και γενικά στο παιχνίδι: αλληλεπίδραση μεταξύ τους!
