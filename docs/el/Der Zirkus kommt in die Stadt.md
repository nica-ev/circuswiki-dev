# Ο Τσίρκος έρχεται στην πόλη

Ένα παιχνίδι συμμετοχής για μεσαίες έως μεγάλες ομάδες παιδιών
Διάφορες εντολές εξηγούνται σύντομα:

1. "Ο τσίρκος έρχεται στην πόλη" --> όλοι φωνάζουν δυνατά "Χουρά" και υψώνουν τα χέρια στον αέρα
2. "Υπάρχει ποπ κορν" --> Όλοι πηδούν επί τόπου και φωνάζουν "Ποπ Ποπ Ποπ Ποπ"
3. "Υπάρχει ζαχαρωτή κάνναβη" --> Όλοι περιστρέφονται γύρω από τον εαυτό τους
4. "Υπάρχουν λουκάνικα" --> Όλοι ξαπλώνουν στο πάτωμα και κυλούν μπρος-πίσω
5. "Οι καλλιτέχνες είναι εδώ" --> Όλοι κάνουν αλματάκια
6. "Οι κλόουν είναι εδώ"

Αυτή η λίστα μπορεί να επεκταθεί / αλλάξει κατά βούληση
Σημαντικός είναι ο "τελευταίος σταθμός"

1. "Τα λιοντάρια ταΐζονται" Όλοι πηγαίνουν στο κλουβί των λιονταριών και ταΐζουν τα λιοντάρια
2. "Τα λιοντάρια είναι ελεύθερα" --> Τα λιοντάρια δραπετεύουν και προσπαθούν να πιάσουν παιδιά, τα πιασμένα παιδιά γίνονται επίσης λιοντάρια. Υπάρχει ένας, όσο το δυνατόν πιο μακρινός, ασφαλής χώρος όπου τα παιδιά μπορούν να σωθούν

Αρχικά, ορίζονται ένα ή περισσότερα λιοντάρια (κατά προτίμηση ενήλικες/εκπαιδευτές - αλλά μπορούν να χρησιμοποιηθούν και μερικά παιδιά)

Το παιχνίδι είναι κατάλληλο και για μεγάλες ομάδες, αν υπάρχει ο απαραίτητος χώρος.

# Παραλλαγές του θέματος

Η βασική αρχή είναι επίσης κατάλληλη για θεματικές παραλλαγές.

Αντί για έναν τσίρκο με διάφορους σταθμούς, χρησιμοποιείται π.χ. ένα πειρατικό πλήρωμα, ένα χωριό Ινδιάνων κ.λπ.
