# 1, 2, 3

Παιχνίδι για οποιοδήποτε μέγεθος ομάδας:

Δημιουργούνται ζευγάρια.

**1ος Γύρος:** Οι σύντροφοι στέκονται αντικριστά και μετρούν εναλλάξ 1, 2, 3 (Μαξ: 1, Λίντα: 2, Μαξ: 3, Λίντα: 1, Μαξ: 2...).
**2ος Γύρος:** Αντί να λένε το 1, τώρα θα χτυπούν παλαμάκια (Μαξ: χτυπάει παλαμάκια, Λίντα: 2, Μαξ: 3, Λίντα: χτυπάει παλαμάκια, Μαξ: 2...).
**3ος Γύρος:** Αντί για το 2, τώρα θα πηδούν επί τόπου (Μαξ: χτυπάει παλαμάκια, Λίντα: πηδάει, Μαξ: 3, Λίντα: χτυπάει παλαμάκια, Μαξ: πηδάει, Λίντα: 3...).
**4ος Γύρος:** Αντί για το 3, θα κάνουν μια στροφή γύρω από τον άξονά τους (Μαξ: χτυπάει παλαμάκια, Λίντα: πηδάει, Μαξ: στρίβει, Λίντα: χτυπάει παλαμάκια...).

Οι γύροι μπορούν στη συνέχεια να αναιρεθούν με αντίστροφη σειρά, μέχρι να φτάσετε ξανά στην αρχική μέτρηση.
