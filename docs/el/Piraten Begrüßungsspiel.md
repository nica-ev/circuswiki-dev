# Παιχνίδι Καλωσορίσματος Πειρατών

Ένα θεματικό παιχνίδι για ομάδες οποιουδήποτε μεγέθους. Το παρακάτω κείμενο τραγουδιέται και συνοδεύεται από αντίστοιχες χειρονομίες / κινήσεις.

"**Γεια σου πειρατή, φαίνεσαι τολμηρός.**
*[ Δείχνει σε έναν άλλο πειρατή ]*
**Βγάλε τον γάντζο σου να δούμε.**
*[ Λυγίζει τους δείκτες, δείχνει ο ένας στον άλλο και γαντζώνει τους δακτύλους ]*
**Γάντζο κούνα, κούνα, κούνα, κούνα.**
[ Οι γαντζωμένοι δείκτες κουνιούνται ]*
**Και στο ξύλινο πόδι τράβα, τράβα, τράβα, τράβα.**
[ Σκύβει μπροστά, σηκώνει ένα πόδι, αρπάζει ο ένας το πόδι του άλλου και το τραβάει ]*
**Και μετά κουτσάνε, κουτσάνε, κουτσάνε, κουτσάνε.**
[ Αφήνει τα πόδια και απομακρύνεται κουτσαίνοντας ]*
**Και στον επόμενο χαιρετάνε, χαιρετάνε, χαιρετάνε, χαιρετάνε.**
[ Στοχεύει τον επόμενο πειρατή και του χαιρετάει ]*
"
