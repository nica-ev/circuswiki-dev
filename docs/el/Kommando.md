# Εντολή

**Μέγεθος ομάδας**: 6 έως 25 παίκτες
**Δυσκολία**: εύκολο
**Υλικά**: χαλάκια ή άλλες σημάνσεις θέσεων
**Διάρκεια παιχνιδιού**: 4 έως 7 λεπτά

**Περιγραφή παιχνιδιού**:
Όλοι οι παίκτες, εκτός από έναν, κάθονται σε ένα χαλάκι ή σε μια άλλη θέση που είναι σαφώς σημαδεμένη με κάτι. Οι θέσεις είναι διατεταγμένες σε κύκλο και στη μέση του κύκλου βρίσκεται ο παίκτης που δεν έχει θέση. Αυτός δίνει τώρα μια συγκεκριμένη εντολή, για παράδειγμα λέει: «Εντολή: όποιος έχει πάει ποτέ στη Βαλτική Θάλασσα» ή «Εντολή: όποιος φοράει πράσινες κάλτσες» ή ό,τι του έρθει εκείνη τη στιγμή. Όλοι οι παίκτες στους οποίους ταιριάζει η εντολή, πρέπει τώρα να σηκωθούν γρήγορα και να βρουν μια νέα θέση. Ο παίκτης στη μέση μπορεί να προσπαθήσει να αρπάξει μια από τις θέσεις που αδειάζουν. Αν τα καταφέρει, αυτός που μένει έξω πρέπει να δώσει μια νέα εντολή. Επιπλέον, υπάρχουν οι ακόλουθες τρεις εντολές που μπορούν να ειπωθούν οποιαδήποτε στιγμή, όταν κάποιος βρίσκεται στη μέση:

- Εντολή αριστερά: Όλοι πρέπει να μετακινηθούν στη θέση αριστερά τους.
- Εντολή δεξιά: Όλοι πρέπει να μετακινηθούν στη θέση δεξιά τους.
- Εντολή γύρω-γύρω: Όλοι πρέπει να κάνουν ένα γύρο γύρω από τη δική τους θέση και να ξανακαθίσουν.

Αυτές οι εντολές χρησιμεύουν μόνο για να φέρουν περισσότερη κίνηση στο παιχνίδι, όχι για να βρει ο παίκτης στη μέση μια θέση.
