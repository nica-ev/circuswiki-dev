# Παιχνίδι Μασάζ - Αγρότης και χωράφι με πατάτες

Ένα παιχνίδι μασάζ για μικρές έως μεσαίες ομάδες.
Εξαιρετικά κατάλληλο και για μικρότερα παιδιά.

Όλοι κάθονται σε κύκλο, πρέπει να υπάρχει άρτιος αριθμός ατόμων (συμπεριλαμβανομένου του συντονιστή) ώστε ο καθένας να έχει έναν παρτενέρ. Αν ο αριθμός δεν είναι άρτιος, ο συντονιστής μπορεί να "βοηθήσει" ένα ζευγάρι.
