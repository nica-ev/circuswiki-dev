> [!info] Σύντομη περιγραφή
> Ένα παιχνίδι κυνηγητού με μαντήλια, όπου όλοι προσπαθούν να κλέψουν τις "ουρές" των άλλων και να συλλέξουν τις δικές τους.

**Μέγεθος ομάδας**: 5-30 άτομα
**Δυσκολία**: Εύκολο
**Υλικά**: Μαντήλια (ένα ανά άτομο)
**Διάρκεια παιχνιδιού**: Περίπου 10-15 λεπτά

## **Περιγραφή παιχνιδιού**:

Ένα παιχνίδι κυνηγητού για μικρές έως μεσαίες ομάδες, το οποίο είναι κατάλληλο για προθέρμανση.

Απαιτούμενα υλικά: Μαντήλια

Κάθε άτομο βάζει ένα μαντήλι στην πίσω τσέπη του παντελονιού του, έτσι ώστε μια "ουρά" να κρέμεται και να είναι εύκολο να την τραβήξει κάποιος.

Στόχος είναι τώρα να κλέψετε τις ουρές των άλλων και να συλλέξετε όσες περισσότερες ουρές μπορείτε.
Αφού κλέψετε μια ουρά, βάλτε την επίσης πίσω στην τσέπη σας, έτσι ώστε να κρέμεται ένα μεγάλο μέρος και να είναι εύκολο να την πιάσετε.

## **Πηγή**:

Άγνωστη
