# Παιχνίδι με «Ουρίτσες»

> [!info] Σύντομη Περιγραφή
> Ένα παιχνίδι κυνηγητού με κίνηση για μικρές έως μεσαίες ομάδες, ιδανικό για προθέρμανση, όπου ο στόχος είναι να κλέψεις τις «ουρίτσες» των άλλων και να μαζέψεις όσο το δυνατόν περισσότερες εσύ ο ίδιος.

**Μέγεθος Ομάδας**: Μικρό έως Μεσαίο
**Δυσκολία**: Εύκολο
**Υλικά**: Μαντήλια (ένα ανά άτομο)
**Διάρκεια Παιχνιδιού**: Περίπου 10-15 λεπτά

## **Περιγραφή Παιχνιδιού**:

Ένα παιχνίδι κυνηγητού για μικρές έως μεσαίες ομάδες, το οποίο είναι κατάλληλο για προθέρμανση.

Απαιτούμενα υλικά: Μαντήλια

Κάθε άτομο βάζει ένα μαντήλι στην πλάτη, μέσα από το παντελόνι, έτσι ώστε μια «ουρίτσα» να κρέμεται έξω και να είναι εύκολο να την τραβήξεις.

Στόχος είναι τώρα να κλέψεις τις ουρίτσες των άλλων και να μαζέψεις όσες περισσότερες ουρίτσες μπορείς.
Αν έχεις κλέψει μια ουρίτσα, την βάζεις κι αυτήν πίσω στο παντελόνι σου, έτσι ώστε να κρέμεται ένα μεγάλο μέρος της και να είναι εύκολο να την πιάσεις.

## **Πηγή**:

Άγνωστη
