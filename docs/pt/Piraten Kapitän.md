# Capitão Pirata

Um jogo temático para grupos pequenos a médios.
O líder do jogo é o capitão pirata.
Num tapete grande (por exemplo, um tapete de ginástica) está o navio pirata, onde todos os piratas se encontram.

O capitão pode agora dar vários comandos. Por exemplo:
Todos para bombordo
Todos para estibordo
Limpar as pranchas
Todos a remar

Todos ao mar - a este comando, todos os piratas saltam do navio e nadam.
Antes do jogo começar, já foram definidos 2-3 tubarões. Ao comando "Os tubarões vêm aí", estes nadam e tentam comer os piratas (que se transformam então eles próprios em tubarões).
Os piratas tentam salvar-se de volta para o navio o mais rápido possível.
