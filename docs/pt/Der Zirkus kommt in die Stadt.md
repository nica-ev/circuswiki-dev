# O Circo Chega à Cidade

Um jogo participativo para grupos de crianças de médio a grande porte
Vários comandos são brevemente explicados:

1. "O circo chega à cidade" --> todos gritam alto "Hurra" e levantam os braços para o ar
2. "Há pipoca" --> Todos saltam no lugar e gritam "Pip Pip Pip Pip"
3. "Há algodão doce" --> Todos giram sobre si mesmos
4. "Há salsichas" --> Todos se deitam no chão e rolam de um lado para o outro
5. "Os artistas chegaram" --> Todos fazem polichinelos
6. "Os palhaços chegaram"

Esta lista pode ser expandida/alterada conforme necessário
O "último estágio" é importante

1. "Os leões estão a ser alimentados" Todos vão para a jaula dos leões e alimentam os leões
2. "Os leões estão soltos" --> Os leões fogem e tentam apanhar as crianças, as crianças apanhadas também se tornam leões. Existe uma área segura, o mais longe possível, onde as crianças se podem refugiar.

No início, um ou mais leões são designados (preferencialmente adultos/treinadores - mas também se podem usar algumas crianças)

O jogo é bastante adequado para grupos grandes se houver espaço suficiente.

# Variações do Tema

O princípio básico também se presta bem a variações temáticas.

Em vez de um circo com diferentes estações, pode-se usar, por exemplo, uma tripulação de piratas, uma aldeia de índios, etc...
