# Zip Zap

Zip Zap

Jogo para qualquer tamanho de grupo:

Os jogadores formam um círculo.

Existem 4 impulsos diferentes: "Zip" (para a direita), "Zap" (para a esquerda), "Peng" (para qualquer pessoa no círculo) e "Boing" (para devolver o impulso).

Exemplo de fluxo:

O facilitador começa e dá um "Zip" para a pessoa à sua direita com uma palma. Essa pessoa passa o impulso com um "Zip". A terceira pessoa aponta com o dedo para outra pessoa no círculo e diz "Peng". A pessoa "atingida" levanta os braços, inclina a barriga para a frente e diz "Boing", devolvendo o impulso.

Agora, a terceira pessoa passa o impulso para a esquerda e diz "Zap"…

Pode ser jogado indefinidamente, por exemplo, quando o impulso volta para o facilitador.
