# Hospital

**Tamanho do grupo**: A partir de 8 participantes
**Dificuldade**: Simples
**Material**: 2-3 tapetes
**Duração do jogo**: 5-10 minutos

**Descrição do jogo**:

No campo de jogo, são colocados dois ou três tapetes ou pequenas áreas são marcadas de alguma forma – estes são os hospitais. Os jogadores recebem um número de "bichos" (germes/vírus) determinado pelo tamanho do grupo. Os portadores dos bichos tentam agora infetar os jogadores saudáveis, tocando neles, e enfraquecê-los de tal forma que caiam no chão e se deitem. Os jogadores infetados podem ser levados para o hospital por dois ou mais jogadores saudáveis, com um alto grito de "tatütata", e lá depositados. Para isso, são segurados pelos braços e pernas e transportados para os tapetes. Jogadores saudáveis que estão a transportar um paciente (a fazer de ambulância) estão seguros dos portadores dos bichos. No entanto, isto só é válido enquanto a ambulância estiver completa. Se um jogador saudável tentar levar alguém para o hospital sozinho, ele pode ser tocado. Os bichos, claro, não entram nos hospitais, pelo que os jogadores saudáveis estão seguros lá.
