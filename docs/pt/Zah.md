# Zah

**Tamanho do grupo**: A partir de 6 participantes
**Dificuldade**: bastante fácil
**Material**: nenhum
**Duração do jogo**: aprox. 5 minutos

**Descrição do jogo**:
Este também é um jogo de círculo. Uma das pessoas em pé no círculo junta as mãos com as palmas voltadas uma para a outra acima da cabeça; essa pessoa tem a "energia". Ela passa a energia para outra pessoa com um "Zah" alto, apontando com as mãos acima da cabeça. O jogador para quem se aponta recebe a energia. Para isso, ele faz o movimento inverso: junta as palmas das mãos e leva as mãos de frente para o corpo para cima da cabeça. Durante o movimento, o jogador grita novamente "Zah" em voz alta. Os dois vizinhos desse jogador agora o "cortam" lateralmente. Para isso, ambas as mãos são juntadas e passadas ao lado dele com um "Zah" alto. Sem toque! Se o jogador que tem a energia for "cortado", ele, assim como o primeiro jogador, passa a energia para alguém do círculo. Se todos os participantes entenderam o jogo, pode-se jogar Zah com eliminação. Se alguém for muito lento, esquecer de gritar Zah, fizer um movimento errado ou cometer outro erro, essa pessoa deve sentar-se. Mas atenção! Assim formam-se novos vizinhos para o "corte", pois apenas os jogadores que estão de pé podem participar. Assim, um, dois, três, cinco ou dez participantes podem sentar-se no meio, e você ainda assim será sempre o vizinho do próximo jogador em pé. Zah é mais divertido quando é jogado bem rápido!

**Extensão**:
Para aqueles para quem o comando "Zah" é muito monótono, podem ser usados sons diferentes. A energia é enviada: Zah. A energia é recebida: Zii. A energia é cortada: Zoh. E o jogo torna-se significativamente mais desafiador.
