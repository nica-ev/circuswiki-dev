> [!info] Breve Descrição
> Um jogo rápido de círculo de energia, onde impulsos são recebidos e passados com movimentos claros.

**Tamanho do Grupo**: A partir de 6 participantes
**Dificuldade**: Bastante fácil
**Material**: Nenhum
**Duração do Jogo**: Aprox. 5 minutos

## **Descrição do Jogo**:

Este também é um jogo de círculo. Uma das pessoas em pé no círculo junta as mãos com as palmas voltadas uma para a outra acima da cabeça; essa pessoa tem a "energia". Ela passa a energia para outra pessoa com um "Zah!" alto, apontando com as mãos acima da cabeça para outra pessoa. O jogador para quem se aponta recebe a energia. Para isso, ele faz o movimento inverso: junta as palmas das mãos e leva as mãos de frente para o corpo para cima da cabeça. Ao fazer o movimento, o jogador grita novamente "Zah!". Os dois vizinhos desse jogador agora o "cortam" lateralmente. Para isso, ambas as mãos são juntadas e passadas com um "Zah!" alto ao lado dele. Sem toque! Se o jogador que tem a energia for "cortado", ele, assim como o primeiro jogador, passa a energia para alguém do círculo. Se todos os participantes entenderem o jogo, pode-se jogar com eliminação. Se alguém for muito lento, esquecer de gritar "Zah!", fizer o movimento errado ou cometer outro erro, essa pessoa deve sentar-se. Mas atenção! Assim, novos vizinhos se formam no "corte", pois apenas os jogadores que estão de pé podem participar. Assim, um, dois, três, cinco ou dez participantes podem sentar-se no meio, e você ainda assim é sempre o vizinho do próximo jogador em pé. O "Zah!" é mais divertido quando é jogado bem rápido!

## **Variantes**:

Para aqueles que acham o comando "Zah" muito monótono, podem ser usados sons diferentes. A energia é enviada: Zah. A energia é recebida: Zii. A energia é cortada: Zoh. E o jogo já se torna significativamente mais desafiador.
