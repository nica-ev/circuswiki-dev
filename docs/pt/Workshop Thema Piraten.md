# Tema do Workshop: Piratas

É especialmente recomendado para crianças em idade pré-escolar integrar as disciplinas de forma temática. Um tema popular é, sem dúvida, "Piratas".

Formas simples de incorporar o equilíbrio na corda incluem:

- atravessar um desfiladeiro profundo em busca do tesouro pirata

De forma semelhante, podem ser encontradas aplicações temáticas para (quase) todas as disciplinas.

- Arte aérea: escalar o navio na cordame
- Malabarismo com panos: panos vermelhos são usados como fogo onde se assam marshmallows/maçãs, estes ficam quentes e precisam ser passados de mão em mão
