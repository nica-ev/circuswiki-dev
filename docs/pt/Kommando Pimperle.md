# Comando Pimperle

Jogo para qualquer tamanho de grupo:

Todas as pessoas sentam-se em círculo.
As mãos são estendidas para o centro e os dedos indicadores batem no chão.
O(A) condutor(a) do jogo pode agora dar vários comandos:
- Plano (os dedos são colocados no chão)
- Costas (os dedos são colocados virados para cima no chão)
- Ponte (as mãos formam uma ponte no chão)
- Pedra (os punhos são colocados no chão)
- Barra (os dedos apontam para o ar)
No entanto, estes comandos só podem ser executados se o(a) condutor(a) do jogo disser a palavra "Comando" antes de cada instrução (por exemplo, "Comando Pedra").
Se não o disser, mas apenas o comando em si (por exemplo, "Pedra"), deve continuar a bater no chão com os dedos. O(A) condutor(a) do jogo pode, no entanto, executar sempre o comando para confundir os outros jogadores.
Se alguém cometer um erro, terá de dar uma volta ao círculo a correr.

Variação: O jogo também pode ser jogado em pé.
Para isso, em vez de bater no chão, corre-se no mesmo lugar. Os comandos são agora executados com o corpo.
- Plano (deitar-se de barriga para baixo)
- Costas (deitar-se de costas)
- Ponte (colocar mãos e pés no chão, esticar o rabo para o ar)
- Pedra (ajoelhar-se no chão e encolher-se o máximo possível)
- Barra (esticar os braços para cima, pernas juntas)
Após cada execução dos comandos, continua-se a correr no mesmo lugar.

Os comandos também podem ser adaptados ao grupo etário.
Para crianças pequenas, podem ser usadas, por exemplo, imitações de animais (sapo, cobra, elefante...).
