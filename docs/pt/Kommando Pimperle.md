> [!info] Breve Descrição
> Um jogo de reação em que os comandos só podem ser executados se forem anunciados com a palavra-sinal.

**Tamanho do grupo**: a partir de 3 pessoas
**Dificuldade**: fácil
**Material**: nenhum
**Duração do jogo**: 5-10 minutos

## **Descrição do Jogo**:

Todas as pessoas sentam-se em círculo.
As mãos são estendidas para o centro e os dedos indicadores batem no chão.
O(A) facilitador(a) pode agora dar vários comandos:
- Plano (os dedos são colocados no chão)
- Costas (os dedos são colocados no chão virados para cima)
- Ponte (as mãos formam uma ponte no chão)
- Pedra (os punhos são colocados no chão)
- Barra (os dedos apontam para o ar)
No entanto, estes comandos só podem ser executados se o(a) facilitador(a) disser a palavra "Comando" antes de cada anúncio (por exemplo, "Comando Punho").
Se não o disser, mas apenas o comando em si (por exemplo, "Punho"), deve continuar a bater no chão com os dedos. O(A) facilitador(a) pode sempre executar o comando para confundir os participantes.
Se alguém cometer um erro, terá de dar uma volta ao círculo a correr.

## **Variantes**:

O jogo também pode ser jogado em pé.
Para isso, em vez de bater no chão, corre-se no lugar. Os comandos são agora executados com o corpo.
- Plano (deitar-se de bruços)
- Costas (deitar-se de costas)
- Ponte (colocar as mãos e os pés no chão, esticar o rabo para o ar)
- Pedra (ajoelhar-se no chão e encolher-se o máximo possível)
- Barra (esticar os braços para cima, pernas juntas)
Após cada execução dos comandos, continua-se a correr no lugar.

Os comandos também podem ser adaptados ao grupo etário.
Para crianças pequenas, por exemplo, podem ser usadas imitações de animais (sapo, cobra, elefante...).
