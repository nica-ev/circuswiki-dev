# Combate Tripartido

Três campos de jogo relativamente apertados e de igual dimensão são delimitados/marcados num tapete (dependendo do número de participantes, podem ser usadas áreas maiores).

Todos começam no campo do meio.
É permitido e encorajado o "rangeln" (luta corporal lúdica). Empurrar, deslizar e puxar (não pela roupa) são bem-vindos.

O objetivo é tentar empurrar os outros participantes para fora do campo de jogo ou para o campo seguinte.
Quem estiver no segundo ou terceiro campo pode também puxar ativamente participantes dos campos anteriores para si.

Ganha quem permanecer por último no campo 1.

Importante: O(A) facilitador(a) do jogo deve ter muito cuidado para que tudo decorra num quadro lúdico e que a luta corporal não escale para agressões violentas.
