# Imagens

Atividade para grupos de aproximadamente 4 a 8 pessoas.

## Etapa I

Os grupos têm, alternadamente, 7 segundos para criar uma "imagem" com os seus corpos.

A palavra-chave pode ser explícita para todos ou secreta para os outros grupos. Na segunda variante, jogamos um jogo de mímica em grupo.

Exemplos de palavras-chave:

- vaso de flores
- flor
- guarda-chuva
- carro
- mesa
- pente
- batedeira
- caneca
- prato

## Etapa II

Adicionamos 3 a 7 segundos à contagem. O objetivo e as regras são os mesmos, mas o grupo pode usar adereços de circo.
