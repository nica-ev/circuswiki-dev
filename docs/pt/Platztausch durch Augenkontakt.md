# Troca de Lugares por Contato Visual

Um jogo em círculo para grupos pequenos a médios.
Todos ficam em círculo. Tenta-se estabelecer contato visual com outra pessoa e confirmar esse contato com um leve aceno de cabeça. Uma vez estabelecido o contato dessa forma, os lugares são trocados, simplesmente caminhando pelo centro do círculo e, assim, trocando de lugar com a pessoa com quem o contato foi estabelecido.

Todos jogam ao mesmo tempo – isso treina a atenção e a comunicação. É preciso estar atento para perceber quem está olhando para você e querendo trocar de lugar.

Como extensão, o contato exigido pode ser cada vez mais restrito – no início, um aceno de cabeça ainda é necessário, o que se refina progressivamente até que apenas o contato visual decida se os lugares são trocados ou não.

# Variação

A variação consiste em diminuir os sinais necessários para um contato bem-sucedido.
No final, basta um simples olhar, sem outros sinais corporais, para estabelecer e confirmar o contato.
