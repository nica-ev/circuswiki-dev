# Jogo de Massagem - Fazendeiro e Campo de Batatas

Um jogo de massagem para grupos pequenos a médios.
Excelente também para crianças mais novas.

Todos sentam-se em círculo. Deve haver um número par de pessoas (incluindo o facilitador) para que todos tenham um parceiro. Se o número for ímpar, o facilitador pode "ajudar" um par.
