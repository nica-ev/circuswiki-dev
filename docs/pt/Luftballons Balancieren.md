# Equilibrar Balões

Um jogo para grupos pequenos a grandes.

Material: Balões

Um jogo simples para praticar os fundamentos do equilíbrio.

Cada pessoa pega um balão e tenta equilibrá-lo pelo maior tempo possível em diferentes partes do corpo.
Por exemplo: no nariz, na cabeça, nos dedos estendidos, no punho, etc.
