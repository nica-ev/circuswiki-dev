# Ordenar em Grupo

Um jogo de cooperação para grupos pequenos a médios.

**Material:** Cadeiras ou bancos, etc., um para cada pessoa.

As cadeiras são dispostas em círculo, com um pequeno espaço entre elas, de modo que se possa passar confortavelmente de uma cadeira para a outra.

Cada pessoa sobe agora para uma cadeira. A tarefa do grupo é organizar-se sem que ninguém toque no chão.

A organização pode ser feita, por exemplo, por nome, altura, idade, etc.

Para dificultar, pode-se proibir a comunicação verbal.
Colocar as cadeiras em fila em vez de em círculo também torna a tarefa mais difícil.
