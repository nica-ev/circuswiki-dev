# Ninguém Gosta de Ficar Sozinho

**Tamanho do grupo**: a partir de 8 participantes
**Dificuldade**: simples
**Material**: nenhum
**Duração do jogo**: enquanto for divertido

**Descrição do jogo**:
Todos os jogadores formam pares num círculo, exceto um, que fica sozinho. O jogador que está sozinho pode chamar um nome. A pessoa chamada tenta correr rapidamente para o jogador solitário. Mas ninguém gosta de ficar sozinho: por isso, o parceiro de quem foi chamado tenta segurá-lo pelos ombros ou abraçá-lo rapidamente antes que ele possa fugir. Ele não pode correr atrás dele! Se já for tarde demais, ele pode chamar outro nome e assim conseguir um novo parceiro ao seu lado.

**Variação do jogo para avançados**:
Para quem achar isto muito fácil, pode jogar de forma que cada um adote o nome do seu parceiro atual. Ou seja, os pares trocam de nomes. Se durante o jogo o vizinho trocar, os nomes também trocam novamente.
