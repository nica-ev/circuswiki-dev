# **Corrida de Almofadas**

**Tamanho do grupo**: A partir de 10 participantes, preferencialmente um número par
**Dificuldade**: Média
**Material**: Nenhum
**Duração do jogo**: Aprox. 3 minutos

## **Descrição do jogo**:

Para preparar o jogo, todos os participantes são divididos em dois grupos iguais. As equipas sentam-se ou ficam de pé alternadamente: num círculo. Dois jogadores sentados um em frente ao outro recebem uma almofada cada. O(a) líder do jogo define uma direção comum para a qual a almofada se move. Cada almofada é passada apenas dentro de uma equipa. Consequentemente, a almofada deve ser passada sempre para o vizinho direto sentado, para a pessoa seguinte da própria equipa. O objetivo do jogo é alcançar a almofada da equipa adversária. No entanto, uma equipa não pode impedir a outra, e as almofadas só podem ser passadas, não atiradas.

## **Extensão**:

O(a) líder do jogo introduz o sinal "Mudança de direção". Após este sinal, a almofada deve mudar de direção. Adicionalmente, pode ser introduzido o comando "Volta", no qual o jogador que tem a almofada na mão deve passá-la uma vez à volta do próprio corpo.

Em vez de almofadas, podem ser usados outros objetos fáceis de passar.
