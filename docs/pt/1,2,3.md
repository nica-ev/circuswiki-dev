# 1, 2, 3

Jogo para qualquer tamanho de grupo:

Formam-se pares.

**1.ª Rodada:** Os parceiros ficam um de frente para o outro e contam alternadamente 1, 2, 3 (Máx.: 1, Linda: 2, Máx.: 3, Linda: 1, Máx.: 2...).
**2.ª Rodada:** Em vez de dizer "1", bate-se palmas (Máx.: bate palmas, Linda: 2, Máx.: 3, Linda: bate palmas, Máx.: 2...).
**3.ª Rodada:** Em vez de dizer "2", salta-se no lugar (Máx.: bate palmas, Linda: salta, Máx.: 3, Linda: bate palmas, Máx.: salta, Linda: 3...).
**4.ª Rodada:** Em vez de dizer "3", dá-se uma volta completa sobre si mesmo (Máx.: bate palmas, Linda: salta, Máx.: vira-se, Linda: bate palmas...).

As rodadas podem, em seguida, ser desfeitas de trás para a frente, até se voltar à contagem inicial.
