# Jogo de Atenção com Bolas

Jogo para grupos pequenos e médios.
Todos correm livremente numa área de jogo delimitada.
(ver também correr livremente / exercícios de teatro / preencher o espaço)
Uma pessoa tem uma bola. Essa pessoa, enquanto corre, estabelece contacto visual com outra pessoa e atira-lhe a bola.

Importante: a pessoa que recebe a bola deve estar relativamente perto, e só se deve atirar a bola depois de ter estabelecido contacto visual.

O nível de dificuldade pode ser aumentado conforme desejado, aumentando o número de bolas.
