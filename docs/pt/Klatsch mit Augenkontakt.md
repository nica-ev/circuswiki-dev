# Bater Palmas com Contato Visual

Jogo de palmas para qualquer tamanho de grupo:

Todas as pessoas formam um círculo.
O líder do grupo começa e passa uma palma através do contato visual para qualquer pessoa no círculo. Essa pessoa procura o contato visual com outra e a passa adiante…
O líder do jogo pode introduzir quantas palmas adicionais desejar. Quando uma palma retorna ao líder, ela não é mais passada adiante.
O jogo termina quando todas as palmas retornarem ao líder do jogo.
