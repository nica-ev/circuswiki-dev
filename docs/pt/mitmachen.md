Estão todos convidados a participar na documentação.
Possíveis temas incluem:
 - Tutoriais
 - Descrições de jogos
 - Alterações / Adições a páginas existentes
 - Ou outra coisa =)

## Documentos de Texto
A forma mais simples de contribuir é enviar o vosso conteúdo por documento de texto (Word, Markdown, TXT, etc.) por e-mail para nós (mailto:info@nica.network)

# Páginas / Blog do Wordpress
Se preferirem criar o vosso conteúdo no Wordpress, enviem-nos simplesmente o link para a página. Na maioria dos casos, o conteúdo pode ser transferido sem grandes problemas.

# Editar / Adicionar os Nossos Documentos
Isto é um pouco mais complexo tecnicamente, mas oferece a possibilidade de editar toda a documentação em formato Markdown (por exemplo, com o Obsidian).
