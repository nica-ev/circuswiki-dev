# Fogo Água Areia

**Tamanho do grupo**: A partir de 4 participantes
**Dificuldade**: Fácil
**Material**: Área de jogo com elevações (por exemplo, bancos), opcional
**Duração do jogo**: 5-15 minutos

## **Descrição do Jogo**:

Todos os jogadores movem-se livremente pelo espaço. Se houver um tambor disponível, o(a) condutor(a) do jogo pode ditar um ritmo, ao qual os jogadores se movem pelo espaço – ora mais rápido, ora mais devagar. Em seguida, o(a) condutor(a) do jogo pode dar vários comandos que os jogadores devem executar.

**Comandos**:

**Fogo**: Com este comando, o(a) condutor(a) do jogo aponta na direção onde está a "arder". Os jogadores devem, portanto, mover-se o mais rápido possível para o lado oposto, para se afastarem o máximo possível do fogo.

**Água**: Todos os jogadores devem subir rapidamente para algo elevado, de modo a não tocarem mais no chão.

**Areia**: Quando este comando é dado, todos se deitam rapidamente de bruços no chão para não afundarem na areia.

**Gelo**: Todos congelam no lugar.

**Sol**: Todos os jogadores deitam-se de costas no chão, como se estivessem a apanhar sol.

**Pastilha elástica**: Este comando faz com que todos os jogadores tenham de se colar a uma parede.

**Café**: Os jogadores sentam-se em posição de índio no chão e batem palmas três vezes.

**Cola**: Tal como num copo de cola, cada um se levanta direito e estica um braço para cima, que é o canudo.

**Besouro**: Todos se deitam de costas, esticam braços e pernas para o ar e tentam virar-se em vão durante alguns segundos.

**Batatas fritas**: Em grupos de três, os jogadores devem deitar-se lado a lado com este comando. (Se o número de jogadores não for divisível por três, grupos de quatro também servem).

**Tempestade**: Todos devem segurar-se a algo para não serem levados pelo vento.

Em relação aos termos, pode-se ser muito criativo e inventar muitos outros comandos para jogar. Este jogo pode ser jogado muito bem com eliminação, onde o mais lento ou aquele que se comporta incorretamente é eliminado.

## **Variante do Jogo**

"Salva-se quem puder" é o nome desta variante. O princípio é o mesmo, apenas o(a) condutor(a) do jogo pode ser ainda mais criativo(a). Pois sempre que disser "Salva-se quem puder...", os jogadores têm de executar este comando. Exemplo: "Salva-se quem puder saltar num pé só". O que ele(a) insere no espaço em branco fica totalmente ao seu critério. Seja saltar num pé só, enfiar o dedo no nariz ou rodar em círculo, tudo o que o(a) condutor(a) do jogo imaginar é possível.
