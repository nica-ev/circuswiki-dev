> [!info] Breve Descrição
> Um jogo dinâmico de aquecimento para qualquer tamanho de grupo, que combina movimento, coordenação e diversão.

**Tamanho do Grupo**: Qualquer
**Dificuldade**: Fácil
**Material**: Nenhum
**Duração do Jogo**: Aprox. 5-10 minutos

## **Descrição do Jogo**:

Todas as pessoas ficam em círculo e imitam os movimentos do(a) condutor(a) do jogo.

| Texto                                  | Movimento                                                                  |
| :------------------------------------ | :------------------------------------------------------------------------ |
| Numa casa bem, bem grande           | Fazer-se bem grande (esticar os braços)                                  |
| Vive um ratinho pequenino             | Fazer-se bem pequeno no chão (agachar)                                      |
| E nessa casa bem, bem grande       | Fazer-se bem grande (esticar os braços)                                  |
| Vive também um cão                     | Pôr pés e mãos no chão, rabo para o ar (posição de cão)               |
| Muito saudável                            | Levantar a perna esquerda (manter a posição de cão)                      |
| Mesmo muito saudável                   | Levantar a perna direita (manter a posição de cão)                     |
| E nessa casa bem, bem grande          | Fazer-se bem grande (esticar os braços)                                  |
| Vive também uma cobra                 | Deitar-se de barriga para baixo (ondular)                                        |
| Fica o cão muito assustado             | Pôr pés e mãos no chão, rabo para o ar (posição de cão assustado) |
| E foge - para uma casa nova | Trocar de lugar (procurar rapidamente um novo lugar no círculo)                |

No final da história, os lugares são trocados de forma que todos fiquem novamente em círculo, mas num lugar diferente.
A história repete-se e é contada cada vez mais depressa.
