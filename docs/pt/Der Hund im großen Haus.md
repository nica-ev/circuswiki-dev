> [!info] Breve Descrição
> Um jogo narrativo de aquecimento em que o grupo encena uma curta história com movimentos correspondentes.

**Tamanho do Grupo**: 5-30 pessoas
**Dificuldade**: Fácil
**Material**: Nenhum
**Duração do Jogo**: Aprox. 5-10 minutos

## **Descrição do Jogo**:

Todas as pessoas ficam em círculo e imitam os movimentos do(a) condutor(a) do jogo.

| Texto                                  | Movimento                                                                  |
| :------------------------------------ | :------------------------------------------------------------------------ |
| Numa casa grande, grande               | Fazer-se muito grande (esticar os braços)                                  |
| Vive um ratinho pequenino             | Fazer-se muito pequeno no chão (agachar-se)                                      |
| E nesta casa grande, grande           | Fazer-se muito grande (esticar os braços)                                  |
| Vive também um cão                     | Pôr pés e mãos no chão, rabo para o ar (posição de cão)               |
| Muito saudável                         | Esticar a perna esquerda (manter a posição de cão)                      |
| Realmente muito saudável               | Esticar a perna direita (manter a posição de cão)                     |
| E nesta casa grande, grande          | Fazer-se muito grande (esticar os braços)                                  |
| Vive também uma cobra                 | Deitar-se de barriga para baixo (ondular)                                        |
| O cão fica com muito medo             | Pôr pés e mãos no chão, rabo para o ar (posição de cão assustado) |
| E foge - para uma casa nova | Mudar de lugar (procurar rapidamente um novo lugar no círculo)                |

No final da história, muda-se de lugar de forma que todos fiquem novamente em círculo, mas num sítio diferente.
A história repete-se e é contada cada vez mais depressa.
