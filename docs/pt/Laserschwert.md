# Sabre de Luz

Um jogo de reação para grupos pequenos a médios.

Um jogador é o "portador do sabre de luz" – este jogador fica à frente, virado para o resto do grupo. Ele faz movimentos **lentos** com o sabre (golpes no centro, de um lado para o outro na altura da cabeça, etc.).

Os restantes jogadores agem como mercúrio – quando o sabre invisível se aproxima, o grupo afasta-se rapidamente nesse ponto, para depois se reagrupar tão rapidamente quanto possível numa formação homogénea.

Os movimentos lentos do portador do sabre são importantes para que os outros tenham tempo de reagir.
