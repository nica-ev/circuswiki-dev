# Cada Um Pega Um

**Tamanho do grupo**: A partir de 10 participantes
**Dificuldade**: muito fácil
**Material**: nenhum
**Duração do jogo**: aprox. 3 minutos

## **Descrição do Jogo**:
Este jogo é rápido de explicar e, na maioria das vezes, rápido de jogar, mas traz bastante movimento para o grupo. Como o nome sugere, cada um tenta pegar o outro. No entanto, um jogador só pode tocar em alguém e ser tocado na área entre as escápulas (omoplatas). Quem for tocado senta-se simplesmente e espera até que a rodada termine. A rodada termina quando apenas um jogador permanecer de pé. Ficar de costas para uma parede ou deitar no chão é, claro, PROIBIDO!

**Extensão 1**: Adicionalmente, os jogadores sentados também podem tocar. Estes podem então tocar nos jogadores em todo o corpo.

**Extensão 2**: Para quem a versão normal termina muito rapidamente, pode-se introduzir a regra de que os jogadores sentados podem se libertar tocando num jogador livre. Para os jogadores sentados, tal como na extensão 1, a regra das escápulas não se aplica, eles podem tocar nos colegas em qualquer lugar.
