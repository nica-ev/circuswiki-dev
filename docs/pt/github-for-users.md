# Participar na Documentação – É Fácil!

Olá a todos! Ficamos muito felizes por quererem ajudar na nossa documentação. 😊 Aqui está um guia simples de como podem fazê-lo:

## O que precisas

1.  **Conta GitHub:**
    *   Cria uma conta gratuita no GitHub se ainda não tiveres uma: [https://github.com/join](https://github.com/join)
    *   Precisamos disto para que tudo funcione.

2.  **GitHub Desktop:**
    *   Descarrega e instala o GitHub Desktop: [https://desktop.github.com/](https://desktop.github.com/)
    *   Este programa facilita o trabalho com o Git, mesmo que não tenhas muita experiência com ele.

## Vamos a isso!

1.  **Copiar o repositório:**
    *   Vai à nossa área de documentação no GitHub (por exemplo, `nica-ev/docs`) e clica no botão "Fork".
    *   Isto cria uma cópia pessoal da área onde podes trabalhar sem estragar nada. 😉

2.  **Trazer o repositório para o teu computador:**
    *   Abre o GitHub Desktop.
    *   Clica em "File" -> "Clone repository...".
    *   Seleciona a tua cópia da área na lista do GitHub.
    *   Escolhe uma pasta no teu computador onde queres guardar a área.
    *   Clica em "Clone".
    *   Agora tens uma cópia da área no teu computador.

3.  **(Opcional) Criar uma nova área de trabalho:**
    *   No GitHub Desktop, clica no botão "Current Branch" (geralmente no canto superior esquerdo).
    *   Introduz um novo nome para a tua área de trabalho (por exemplo, `nova-página`, `corrigir-erro`).
    *   Clica em "Create branch".
    *   As áreas de trabalho ajudam a separar as tuas alterações. Se algo correr mal, podes simplesmente apagar a área de trabalho.
    *   **Nota:** Criar uma nova área de trabalho é opcional, mas é uma boa ideia para organizar as tuas alterações.

4.  **Fazer alterações:**
    *   Usa o teu editor de texto (por exemplo, Notepad, VS Code) para editar os ficheiros na área no teu computador.
    *   Aqui podes adicionar textos, corrigir erros, etc.
    *   **Importante:** Usa Markdown para a formatação (ver abaixo).

5.  **Guardar alterações:**
    *   No GitHub Desktop, no separador "Changes", verás os teus ficheiros alterados.
    *   Escreve um breve resumo no campo "Summary".
    *   Clica em "Commit to `<branch-name>`" (ou "Commit to main", se não usaste uma área de trabalho).
    *   Guardar é como criar um ponto de salvaguarda do teu trabalho.

6.  **Carregar alterações:**
    *   No GitHub Desktop, clica em "Push origin".
    *   Isto carrega as tuas alterações para a tua cópia da área no GitHub.

7.  **Submeter alterações para revisão:**
    *   No GitHub Desktop, clica em "Create Pull Request". Isto abrirá uma página no GitHub.
    *   Verifica as tuas alterações lá e clica em "Create Pull Request".
    *   Um Pull Request é como um pedido para que as tuas alterações sejam incorporadas na área principal.

## Importante saber

*   **Markdown:** É como uma linguagem simples para textos. Aqui tens um breve resumo:
    *   `# Título 1`
    *   `## Título 2`
    *   `**Negrito**`
    *   `*Itálico*`
    *   `- Lista`
    *   `[Link](https://www.example.com)`
*   **Mensagens ao guardar:** Escreve mensagens curtas para os teus guardados, para que todos saibam o que fizeste.
*   **Paciência:** No início, pode ser preciso um pouco de prática. Pergunta se algo não estiver claro!

Obrigado por ajudares! 🙌
