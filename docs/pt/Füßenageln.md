# Pregando os Pés

Tamanho do grupo: a partir de 5 participantes
Dificuldade: fácil
Material: nenhum
Duração do jogo: 5-10 minutos

Cada jogador tenta tocar os pés dos outros jogadores com as mãos. Ou seja: cada um contra todos.

Se um jogador conseguir tocar o pé de outro, esse pé fica "pregado" no chão. Isso significa que esse pé não pode mais ser movido do lugar. Com o outro pé – o livre – ainda é possível tentar fugir. Além disso, a qualquer momento outros pés podem ser tocados.
Condição básica para este jogo: todos os jogadores livres devem permanecer em movimento!

O jogo termina quando ninguém ou apenas mais um jogador tiver dois pés livres.
