# Bibbel Di Babbel Di Buh

Um jogo de círculo para grupos pequenos a médios.

Todas as pessoas formam um círculo, e uma pessoa vai para o centro.
A pessoa no centro (P1) começa a apontar para qualquer pessoa (P2) no círculo. É importante apontar claramente para alguém, estabelecer contato visual – de forma que fique muito claro quem é a pessoa escolhida.

Agora, pode-se escolher entre as seguintes regras:

**"Bibbel Di Babbel Di Buh"**: Esta frase é dita por P1, e antes que a frase termine, P2 deve dizer "Buh". Se P2 for muito lento, P2 deve ir para o centro.

**"Buh"**: Quando P1 diz "Buh", P2 não pode reagir. Se P2 disser algo mesmo assim, P2 deve ir para o centro.

**"Torradeira"**: P1 diz "Torradeira" – as pessoas à direita e à esquerda de P2 viram-se para P2 e estendem as mãos ao lado de P2. P2 salta e grita "Bing" (P2 é o pão de torrada, os outros formam a torradeira). Quem fizer algo errado deve ir para o centro.

**"Torradeira avariada"**: Este comando é semelhante a "Torradeira". As pessoas à direita e à esquerda de P2 formam novamente a torradeira, P2 é o pão de torrada, mas desta vez P2 fica parado, enquanto os outros dois saltam e gritam "Bing".

**"Máquina de lavar roupa"**: As pessoas à direita e à esquerda de P2 mantêm as mãos para cima e para baixo, formando um grande círculo à frente de P2 – elas formam a máquina de lavar roupa, e P2 gira a cabeça dentro deste círculo – a roupa a ser lavada.

**"Canguru a vomitar"**: P2 segura as duas mãos à frente, formando a bolsa do canguru. As duas pessoas à direita e à esquerda de P2 inclinam-se sobre a bolsa e fazem sons altos de vómito.
