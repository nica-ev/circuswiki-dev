Uma pessoa fica de costas para as outras, com um objeto pequeno (por exemplo, uma bola) atrás dela.

Sempre que essa pessoa se virar, as outras devem congelar. Quem se mover terá que dar 2 passos para trás (ou voltar ao início).

O objetivo é roubar a bola e levá-la até a linha de partida.
Assim que a bola for levada, a "Rainha do Gelo" pode dar UMA dica sobre quem está com a bola no momento.

Se ela acertar, ela vence.
