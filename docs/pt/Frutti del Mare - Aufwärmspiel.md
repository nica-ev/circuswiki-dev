# Frutti del Mare (Jogo de Aquecimento)

Exercício de aquecimento para grupos pequenos a médios, especialmente adequado para crianças pequenas.

**A Estrela-do-Mar**
Começamos deitados de costas, com braços e pernas esticados para fora do corpo em forma de estrela.

**A Concha**
Viramo-nos para o lado e encolhemos braços e pernas de forma a ficarmos o mais pequenos possível.

**O Cavalo-Marinho**
A concha acorda lentamente e estica-se, ainda deitada de lado, tornando-se assim um cavalo-marinho.

**A Foca**
Caímos de barriga para baixo, levantamos a cabeça, apoiando os braços.
Abanamos a cauda (ou o rabo).

A foca olha para a direita, depois para a esquerda, depois olha para o céu. Estica uma mão em direção às estrelas (o corpo já roda um pouco) e depois cai de costas, voltando a ser uma estrela-do-mar.
O círculo recomeça.
